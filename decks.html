发现更多课程

句子详解

粘贴大模型返回的 JSON 回填 （数组，长度须与意群数一致）

确认操作

移入课程目录

选择要归入的课程目录。

添加课程

选参数或指定句子 → 复制提示词 → 粘回 JSON
1提示词复制给任意外部大模型
2粘贴模型返回的 JSON也可拖入 .json 文件
支持带 ```json 代码块的原始回复，会自动清洗

导入图文课程

一个 ZIP 课程包对应一个课节

点击选择文件 或拖入 ZIP 课程包到此处

支持 .zip 格式（English MUD 导出）
点击选择或拖入封面图片

追加句子

1粘贴已有句子每行一句，建议 30-60 句/批；批量导入会校验去重
支持 .txt 文件（每行一句）· 大模型将给每句拆意群 chunks + 中文翻译 + hints
2Prompt粘贴给任意大模型
3粘贴返回的 JSON自动去重
支持 .json / .txt

批量生成详解

粘贴到外部大模型 → 生成 → 把 JSON 粘贴到下方一次回填

编辑句子

英文句子（必填）
中文翻译（选填）
意群 chunks（每行一个，2-5 个，拼接等于原句）
中文提示 hints（每行一个，与 chunks 同数）
详解 explanations（每行一条）
