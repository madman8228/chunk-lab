## 📌 TL;DR（执行摘要，3-5 行）

1. **真正的瓶颈不是"配置缺失"，是"没有可排名的对象"**：66 个课程包 / 7354 条内容目前只以裸 JSON 存在（`实测`：`/content/manifest.json` 线上 200 且公开可拉取），**能被扒走，却不能被索引成页面**。
2. **技术门是敞开的**：静态根 = 仓库根（`读码`：`server/index.js:427`），静态守卫不拦 `.txt/.xml`（`读码`：`static-guard.js`）⇒ robots / sitemap / 静态内容页 **零架构成本**。
3. **正确顺序是"先造可索引内容页 → 再上技术 SEO"**：只修 robots/sitemap/canonical，天花板 ≈ 0（竞析 + 数析一致判断，【推断】）。
4. **入口词用"症状语言"而非术语**：主入口是"英语句子太长听不懂"这类**症状描述型 query**，不是"意群"（瑞思，【推断·待验证】）⇒ 页面标题以症状词为准，术语词作语义锚点。
5. **合并方案（方案 C：落地页并入 Chunk Lab / 占主域根）老板已定**：本地合并在 **2026-10-05 已完成并验证**（`GET /` 返回落地页 200、无重定向；`/main.html` 200；三档宽度无横向溢出），**线上未执行**，阻塞于"**未获授权执行线上变更 + 服务器身份待按三重特征复核**"。**canonical / sitemap 目标域确定为 `jqka.top`**；现 `chunklab.jqka.top` 需 301 到新域。

## 1. 产品目标（3 个清晰、正交的目标）

> 三个目标彼此正交：**A 管"能不能被搜到"、B 管"搜到后能不能被留住"、C 管"做了到底有没有用"**。

**目标 A（可索引）**：把 Chunk Lab 的唯一独有资产——**按意群切分的题库/语料**——从"裸 JSON"转成"可被搜索引擎与 AI 爬虫抓取的页面对象"。
- 判据方向：爬虫**在不执行 JS** 的情况下能拿到完整正文（当前为「加载中…」空壳，`实测`：练习内容 100% JS 动态渲染）。

**目标 B（可承接）**：在"症状描述型"搜索意图上建立入口，并让落地处的用户**当场可体验**（未登录可体验），把"搜到"转化为"用上"。
- 判据方向：内容页正文对**未登录用户可读**，且页内提供**直接开练入口**。

**目标 C（可度量）**：建立 SEO 度量闭环，结束"搜索归因能力 = 0"的盲飞状态。
- 判据方向：接入站长平台 + 客户端埋点后，能**分层**看到"索引 / 曝光 / 点击 / 注册"四层数据（数析三层指标表，§5.2）。

## 3. 用户研究洞察（来自瑞思：意图匹配取舍 / 发现路径权重 / 落地页期待）

### 3.1 意图匹配取舍（两维度合并口径）
- **用户侧产品匹配度**（瑞思）：能拦住 B 难题型 + D 长尾 + A 工具型（C 备考型产品也能满足）。
- **SEO 可排上**（数析）：只有 B 的**症状词子集**与 A 工具型可达性高；C 备考型巨头垄断（可达性 1 分）；E 竞品型不中立。
- **合并结论（采纳两方口径）**：
  - **主入口**：B 难题型的**症状词子集**（"句子太长听不懂""连起来听不懂"）。
  - **次入口**：A 工具型功能页、D 长尾句子页（观察）。
  - **术语词**（"意群 / 意群划分"）：**做，但作语义锚点/内部承接，非主入口**（需求低、天花板低）。
  - **排除**：C 备考型（瑞思与数析合并表述："用户需求与产品匹配度高，但 SEO 入口竞争过高，不作主战场"）；E 竞品型。
- **投入产出最优顺序【推断】**：症状词子集 **>** D 长尾 ≈ A 工具型 **>** 术语词（锚点）**>** C/E。

### 3.2 发现路径权重 + SEO 可达性
- **权重排序【推断】**：短视频/社媒种草 **>** 搜索查证 ≈ 社群口碑 **>** 应用商店。
- 【来源】艾瑞：2023 年成人在线英语用户约 **58.7%** 经短视频+社媒首次接触品牌（2019 仅 21.3%）；QuestMobile：决策约 4.6 触点 / 12–21 天；移动端百度仍占主导（约 64%–78% 量级）。
- ✅ SEO 吃得到：B 症状词、D 长尾句子词条、A 工具型。
- ❌ 吃不到：短视频种草、私域裂变、应用商店榜单。
- **定位结论**：SEO 的合理定位是"**用户被种草后去搜索时，能搜到你并当场体验**"，**不是主要拉新引擎**。

### 3.3 落地页期待（数秒首屏原则）
1. **一句话价值主张**（示例："把长句拆成意群，跟读练到听懂"），而非品牌哲学。
2. **直接可玩的体验 + 延迟强制注册**：先体验价值再要账号，表单字段 **≤3 项**【来源：SaaS 最佳实践，SSO 约 +8%】。
3. **真实产品界面截图/演示**，而非抽象插画【来源】。
4. **"未登录也能体验一次"的双重意义（关键洞察）**：既是降首屏摩擦提注册（freemium 约 13% 自然流量用户会注册【来源】），**更是让"静态可抓取 HTML 内容"存在的物理前提**——当前内容全 JS 渲染，搜索引擎/AI 爬虫看到的是空壳 = "有内容但不可索引"，这是 SEO 最大的技术损失。

### 3.4 "主域被别的产品占着 + 落地页未上线"的伤害【推断】
- `jqka.top` 根返回 **English MUD**（`实测`）⇒ 用户搜到/点到会**认知错位**（期待英语工具、见到另一个东西），信任归零、跳出率高。
- 落地页未上线（`实测`：仓库 `index.html` 未被线上返回）⇒ 主域缺"品牌说明书"，**AI 搜索无法确认"jqka.top 是什么、给谁用"**，错失被 AI 答案引用。

### 4.4 差异化机会（三个突破口）
1. **意群句页**：每句 = 一个可索引 URL（原句 + 意群切分 + AI 详解 + 词卡）。竞品全是**听力稿级**，无句级意群结构化数据，我方改造成本 ≈ 0，别人从零重建很贵。
2. **意群方法论文章 30–50 篇**：最低成本最快见效；实证现有结果全是纯文章、无互动练习（海外站甚至用中文页蹭词），我方做"文章入口 → 练习承接"闭环。
3. **考试×段位聚合页**："考研口语句式·Queen 段位"等，把搜索意图（考试）与产品机制（J/Q/K/A 段位）绑定——竞品段位体系缺失或与搜索意图脱节，是独家叙事资产。

### 4.5 竞析的核心判断（本方案采纳）
**只修 robots/sitemap/meta/canonical/结构化数据，天花板 ≈ 0**【推断】。技术 SEO 只让"已有页面被索引"，**不生产可排名对象**。当前内容**已结构化存在，却是"裸 JSON"** ⇒ **双重裸奔**：**不可排名**（无 HTML 内容页，爬虫拿空壳）+ **零防护**（竞品/扒站可直接拉走唯一独有资产）。**正确顺序：先造内容页 → 再上技术 SEO**，并同步收紧 `manifest` 公开枚举。

## 5. 数据依据与度量体系（来自数析：现有可测边界 / 三层指标表 / 关键词方向评估）

### 5.1 现在能测 / 不能测（零起点基线）
**【已确认·有数据】**（数析）：
- **nginx access log**：总请求量、状态码分布、UA 粗分（疑似爬虫 vs 浏览器）、Referer。
- **后端接口调用量**（端口 8787）：注册/登录、练习提交、SRS 复习次数——**唯一**能反推业务行为的信号。

**【仍是推断·未验证】**：
- ❌ **"有多少人从搜索来"当前无法测**：搜索跳转常伪装 / Referer 缺失，UA + Referer 无法可靠归因搜索来源。
- ❌ 曝光、点击、CTR、平均排名、关键词 = **0 数据**（仅站长平台有）；新访客/留存/漏斗无埋点不可拆。

**结论**：接入 GSC + 百度搜索资源平台**之前，SEO 效果盲飞，搜索归因能力 = 0**。故"**先拍域名 + 接入站长平台 + 埋点**"是**读数前置条件**。

### 5.2 三层度量指标表（数析）

**① 索引 / 抓取层**
| 指标 | 定义 | 来源 | 频率 | 起效预期 |
|---|---|---|---|---|
| 索引覆盖率 | 已索引 ÷ 已提交 | GSC + 百度 | 周 | 提交后 2–6 周 |
| 提交-索引差 | 提交数 − 收录数 | 同上 | 周 | 同上 |

| robots 拦截数 | 被拦抓取 | GSC | 周 | 立即 |

**② 展现 / 点击层**
| 指标 | 定义 | 来源 | 频率 | 起效预期 |
|---|---|---|---|---|
| 曝光 / 点击 / CTR / 平均排名 | 标准搜索指标 | GSC + 百度 | 周 | 收录后 1–4 周起量 |

**③ 业务衔接层**

|---|---|---|---|---|
| 自然搜索访客 | 搜索来源着陆 | 【推断】GA4/百度 + GSC | 周 | 接入后即 |

**⚠️ 反馈周期判定线（防日活思维误判）**：索引 **4 周**无增长 = 异常；有收录后 **4–8 周**曝光 ≈ 0 = 异常；有曝光后 **8–12 周** CTR < 0.5%（前 20 名）= 异常。**最小观察窗 2–4 周，禁止按天判定。**

**★ 独立验收判据（数析 + 主理人共同确认）**：**"已索引但 0 曝光" ≠ 成功**——这是 JS 空壳的典型表现（**假收录**），必须用预渲染/SSR 产出**真内容页**才能验真。

### 5.4 优先级判据（可用于需求池打分）
**机会分 =（需求 D × 可达性 A × 意图匹配 I）÷ 成本 C**，各维 1–5 分：
- **D**：1=几乎无搜索 / 3=中量长尾 / 5=高量高意图
- **A**：1=巨头垄断无内容 / 3=需新建 / 5=现有资产直接命中
- **I**：1=搜了不来练 / 3=间接 / 5=搜索意图=使用意图
- **C（分母）**：1=极高（重开发/等域名）/ 3=需写内容 / 5=极低（改 meta/加 sitemap）
- 分档：**≥8 立即做 / 4–8 排期 / <4 观察或放弃**。**C=1 的高成本项会把分数拉爆 ⇒ 先冻结至域名拍板。**

### 5.5 线上变更未授权期间的可做 / 须等边界（数析）
- **可做（本机可做，迁域不废）**：① 内容页生产；② 让内容**可被索引**的 HTML 结构改造（治 JS 空壳、语义化标签/标题层级）——**可迁移核心资产**；③ title/description 文案、内链结构、性能与移动适配；④ **JSON-LD（用根相对路径）**；⑤ 用现域在 GSC 挂属性做**技术诊断**（抓取错误、索引、CWV，结论不因迁域作废）。
- **须等线上变更授权**：`sitemap.xml`、`canonical / og:url` 等**绝对域名地址**、robots 里指向 sitemap 的绝对 URL、百度资源平台提交、**对外发外链/推广**、改 nginx / 清 MUD / 部署 / 301。（**目标域已定为 `jqka.top`**，不再是"域未定"。）

### 5.6 会让投入打水漂的度量陷阱（数析，本方案据此设验收）
1. **把爬虫抓取量当用户量**：log 里 200 暴涨多是扫描器 ≠ 有人来学；抓取 ≠ 曝光 ≠ 点击 ≠ 注册，必须分开看。
2. **线上变更未授权前做 sitemap/canonical 之绝对 URL = 白做**：未部署或迁域后旧信号作废、需重做 301 并重提。**先拿到线上变更授权（目标域 `jqka.top`）再上绝对 URL 基建。**
3. **把"收录"当"排名"**：收录只在库，可能 100 名外；**"已索引 0 曝光" = 仍失败**。
4. **JS 渲染空壳被大量收录**：索引率高但曝光 0 的**假收录**，需预渲染/SSR 才能验真。
5. **日活思维判 SEO**：按天看必误判"没效果"，须守 **2–4 周**观察窗。

## 7. 关键流程与页面形态（文字 / ASCII）

### 7.1 "搜索 → 内容页 → 练习"承接闭环（文字流程）
```
[症状词 query]  "英语句子太长听不懂"
      │  搜索
      ▼
[C2 症状词方法论承接页]  ← 标题用症状原词，正文术语锚定
      │  页内 CTA："用意群拆开试试"  (内链)
      ▼
[C3 意群句页]  ← 每句一 URL：原句 / 意群切分 / AI 详解 / 词卡
      │  页内 CTA："开始跟读练习"  (内链)
      ▼
[练习页 main.html]  ← 未登录可体验一次，延迟注册
      │
      ▼
[注册 → 学习档案 / SRS]
```
> 设计要点：整条链**每一跳都是可抓取的静态 HTML**（治 JS 空壳）；未登录用户可在**最后一跳**体验，但**前两跳的正文**必须对爬虫与用户完全可读。

### 7.2 句子详情页（C3）页面形态示例（模板，非代码）
- **URL**：`/s/{句子ID}.html`（**根相对**，迁域不废）
- **标题模板**（症状/长尾语言优先，术语作后缀锚点）：
  - 主：`{句子关键短语 / 句式} 意群怎么断｜{课程名} · Chunk Lab`
  - 例：`there be 句型 意群怎么断｜四级高频口语句式 · Chunk Lab`
- **描述（meta description）模板**：`{原句} —— 按意群切分为 {N} 段，附逐段 AI 详解与跟读练习，未登录可直接体验。`
- **面包屑层级**：`首页 > 课程目录 > {课程名} > {句页}`
- **正文四要素**：① 原句文本；② 意群切分（分段展示）；③ AI 逐段详解；④ 词卡。
- **首屏 CTA**：`开始跟读练习`（指向练习页，**不遮挡正文**）。

### 7.3 方法论文章页（C2/C8）页面形态示例
- **标题模板**：`{症状原词}？用意群拆开试试｜Chunk Lab`（例：`英语句子太长听不懂？用意群拆开试试`）
- **结构**：`H1 症状问句 → 原因解释 → 意群方法讲解 → 示例拆解（内链句页）→ CTA 练习`
- **术语锚点**：正文首次出现"意群"处做**内部承接链接**到 C4 锚点页。

### 7.4 品牌落地页（C1/C6）页面形态示例
- **首屏三件套**：一句话价值主张（"把长句拆成意群，跟读练到听懂"）＋ 直接可玩体验 ＋ 真实界面截图。
- **注册策略**：延迟强制注册（表单 ≤3 项）。
- **AI 可引用要点**：页面显式声明"**jqka.top 是什么、面向谁、能做什么**"（供 AI 搜索摘要引用）。

### 7.5 技术抓取路径（现状 vs 目标）
```
现状：爬虫 GET /main.html  → 200，但正文 = "加载中…"（JS 未执行）  → 空壳，不可索引
目标：爬虫 GET /s/{id}.html → 200，直接返回含 原句/意群/详解 的静态 HTML → 可索引
```

## 8. Non-goals（明确不做什么）

1. **不做词典/翻译工具页**（模式 A）：无词库版权，护城河是别人的。
2. **不打百万级词条战**（模式 B）：词卡量级（数百词）远不够撑长尾。
3. **不以考试大词为主战场**（C 备考型 / 模式 D 大词）：巨头垄断，可达性最低。

10. **本方案不触及部署/服务器/线上接口**：本方案为规格书，**不含任何线上变更**。

### 9.2 各阶段观察窗与达标线

- **M1｜观察窗 2 周**：`curl`（**不执行 JS**）随机 20 个内容页 HTML **无「加载中…」占位**、可读完整句文本与**唯一 H1**；随机 10 页未登录 `curl` 返回 **200** 且正文完整；`manifest` 匿名不再返回 66 包全量（401/403 或精简版）。**未达标→补静态渲染。**
