先说明：这是一份"一次成型"方案

你给的信息是「学习网站 · 客单 10 / 30 / 89 元 · 每天 30 分钟免费 + 付费订阅」。其余参数（用户规模、内容形态、毛利率、数据能力）我**全部按行业基准值代入**，并在第 12 章逐条登记。下面 7 个决策是我替你做的，**如果你的实际情况不同，按每条末尾的"改成 YY"调整即可**。

我替你做的 7 个关键决策

决策 1会员制形态 = 免费额度层 + 付费订阅层「双轨」

免费层内嵌 3 档学习成长等级（拉新与活跃），付费层做 3 档订阅（变现）。两轨目标不冲突：等级只奖励学习行为，订阅只卖时间与服务。

若你的情况是：内容极重、制作成本高、无法承担免费带宽 → 改成"只做订阅 + 3 节免费试看"，取消每日额度。

决策 230 分钟额度 = 「不累积 + 触顶三出口」

零点重置、不累积到次日（累积会削弱付费动机）；触顶后不硬锁，给三个出口：等次日 / 邀请好友得 +15 分钟 / 订阅解锁。额度是转化点，不是惩罚。

若你的情况是：学习内容有强连续性（如连载课程）→ 改成"额度可累积 3 天"，避免中途打断导致弃学。

决策 3三档定价映射 = 月卡 ¥10 / 季卡 ¥30 / 年卡 ¥89

阶梯比例 1 : 3 : 8.9（每跳约 3 倍），是教科书级的健康档梯。年卡日均 ¥0.24，比月付口径省 26%，天然当锚点。

⚠️ 但这套定价有一个洞：季卡 ¥30 = 月卡 ×3，价格上没有任何折扣空间，用户没有升级理由。第 4 章给出修补方案。

决策 4积分定位 = 学习行为驱动（成长值 + 学习豆双轨）

不做消费积分。学习站的核心矛盾是放弃率，钱只能买来订单、买不来学习行为。成长值决定等级（只升不降），学习豆可消耗兑换。

若你的情况是：用户已形成稳定学习习惯、放弃率不是主要矛盾 → 可引入消费积分与订阅挂钩。

决策 5等级权益绝不包含"额外免费时长"

这是学习站最容易犯的错。等级一旦送时长，用户就可以"靠学习攒等级换时长"，直接击穿付费墙。等级只给非时间型权益：报告、资料折扣、笔记容量、内测资格、身份徽章。

若你的情况是：想给最高等级一点特权感 → 最多给"每日 +5 分钟"，且必须测算对订阅转化的侵蚀量。

决策 6北极星 = 30 日免费→付费转化率；领先指标 = 额度耗尽率

转化率是结果，滞后。真正要先动的数是额度耗尽率（QER）——当天用完 30 分钟的免费活跃占比。没用完额度的人，永远不会付费。

若你的情况是：转化率已经不错但续费率低 → 北极星换成"年度续费率"，重心移到权益使用率。

决策 7明确不做：储值次卡、4 档以上、全员折扣券

储值触及单用途预付卡监管且学习站不需要；档数多于人群会稀释感知；全员折扣券补贴的是"本来就会买的人"。

若你的情况是：有线下自习室/面授履约场景 → 储值才重新进入选项，且必须先过法务与财务。

核心结论（三条）
  1. 你真正的问题不是定价，是"没人撞到墙"。额度耗尽率只有 8%，意味着 92% 的免费活跃用户每天都没用完 30 分钟——他们对付费毫无感知。先把 QER 从 8% 推到 22%，转化池自动扩大 2.75 倍。
  2. 季卡（¥30）在纯时长口径下没有任何存在理由。它必须靠"权益差 + 学习周期契合度"立身：离线下载、共修群、一个完整的备考/学期周期。这是本次方案要补的最大一个洞。
  3. 积分是这套体系里最被低估的杠杆。学习站可以拿边际成本≈0 的自有内容（解锁单课、资料包、题库）做积分出口，用 20 : 1 的杠杆把积分负债转成"内容体验 ⇒ 转化"。同样发一轮积分，你的成本只有电商的十几分之一。
本方案明确不做的事
  • 不做储值 / 次卡——触及单用途预付卡监管，且学习站无到店履约场景，收益不抵合规成本
  • 不做 4 档以上订阅——当前规模下会稀释每档感知，先做 3 档把差异做足
  • 不做等级送学习时长——直接击穿付费墙，是学习站最经典的自我拆台
  • 不做积分自由兑换会员时长——必须设上限（每月 ≤2 天），否则等于给所有人发免费会员
  • 不做全员折扣券——把券发给"本来就会学满的人"是纯成本浪费
  • 不做打卡送现金 / 全勤返现——会导致挂机刷时长，且学习动机被外部化

业务现状与适配度判断

先判断该做哪种会员制，再谈怎么设计

结论：应采用「额度墙 Freemium + 三档订阅」双轨制，不建议做纯免费等级制，也不建议做储值/次卡。

理由：学习站有三个特征同时成立——① 用户使用频次极高（理想状态是每日使用，远超"年购买 1.5 次"的会员门槛线）；② 内容边际成本极低（录播/音频/题库复用，一次制作无限分发）；③ 用户的真实痛点不是"买不到"而是"学不完"。前两条让"无限畅学"在经济上成立，第三条决定了整个体系必须围绕"持续学习"而不是"持续消费"来设计。

会员体系架构

双轨结构 · 三档订阅 · 三档成长等级

结论：付费轨做 3 档订阅（¥10 / ¥30 / ¥89），免费轨做 3 档学习等级（学友 / 同修 / 精进）。两轨解耦——等级只由学习行为决定、绝不送时长；订阅只卖时间与服务、绝不加快成长值倍率到失衡。

4.1 付费轨：三档订阅的权益矩阵

先修这个洞：季卡 ¥30 在纯时长口径下毫无理由

¥30 ÷ 3 个月 = ¥10/月，与月卡完全同价。用户不但没有省钱，还把三个月的钱一次性压给了平台。如果不给它独立的权益差，季卡会被理性的用户直接跳过，档梯断在第二级。
修补方案（本方案采用）：季卡与年卡的价值从"价格折扣"改为"权益深度 + 学习周期契合度"。季卡对应一个完整的学习周期（备考 3 个月 / 一个学期），叠加离线下载与共修群；年卡再叠加服务型权益与证书。

4.3 成长值公式

成长值 = 有效学习分钟 × 1 + 完课节数 × 20 + 连续打卡天数 × 5 + 付费金额 × 2 + 邀请好友成功 × 50

权重结构（必须遵守）：学习行为 ≥ 70% / 付费 ≤ 20% / 社交 ≤ 10%。
为什么把付费权重压到 20% 以内：一旦付费能快速堆等级，免费用户会直接判定"等级是花钱买的"，整个成长体系对占 95% 的免费人群立刻失效。等级必须是学习的荣誉，不能是付钱的收据。
只升不降：成长值是累计荣誉，不做年度清零（与"消费额等级"不同——学习行为是沉没投入，清零会引发强烈挫败）。

4.4 为什么不做"降级 / 保级"机制（展开查看）

零售业的等级必须做降级，否则等级会通胀。但学习站的等级建议不做降级，理由有三：

  1. 激励方向不同。零售降级是在施压"继续消费"；而学习站的用户流失原因往往是"时间不够 / 坚持不下去"，降级带来的挫败感会加速放弃，而不是挽救。
  2. 成本极低。等级权益都是非时间型的（报告、折扣、笔记容量），一个不活跃的"精进"用户几乎不产生成本。降级省不下钱。
  3. 情感资产要考虑。等级是用户的"学习履历"。清零或降级，等于告诉用户"你这几个月白学了"。

5.2 权益设计的三条纪律

  1. 每档权益 3–6 项，不超过 6 项。超过后用户记不住，且成本弹性变差。
  2. 相邻档差异必须一眼可辨。如果季卡和月卡的差别只是"多送 5 份资料"，这一级就废了。本方案用离线下载作为月→季的核心分水岭，用答疑 + 证书作为季→年的核心分水岭。
  3. 通用折扣是最差的权益。成本高、无差异、伤品牌，且训练用户等打折。学习站尤其不该打折——因为用户付费买的不是"便宜"，是"能学完"。

双轨设计 · 行为价目表 · 五池模型 · 出口结构

结论：学习站必须做「成长值 + 学习豆」双轨。成长值只升不降、决定等级、不可消耗；学习豆可消耗、可兑换、有有效期。汇率定 1000 学习豆 = 1 元——因为学习站的行为颗粒度细，小额数字更能激励高频动作。

杠杆 = 名义价值 ÷ 实际成本。学习站的单课解锁杠杆可达 16.7×（内容边际成本仅带宽 + 摊销），而电商的实物兑换品通常只有 2–3×。同样发一轮积分，你的成本只有电商的十几分之一——这是学习站积分体系最被低估的优势。

必须设上限：积分不能变成"免费会员"的后门

"兑换会员天数"这个出口一旦不设限，用户会攒积分换会员，订阅收入就被自己的积分体系击穿了。硬约束三条：
① 每月最多兑换 2 天；② 兑换价必须"不划算"（500 豆 = 1 天，而同量豆在内容解锁上价值更高，引导用户去换内容）；③ 兑换的会员天数不计入连续包月、不享受会员权益折扣。

7.2 学习活跃度分群（替代 RFM）

为什么学习站不用 RFM

RFM 的三个维度建立在"购买"上。学习站的用户可能每天都来学（F 极高）却从没付费（M = 0），也可能付费了年卡却再也不来（M 高、R 极差）。对学习站，正确的分层轴是「学习活跃度 × 完成度 × 订阅状态」，而不是「消费额 × 频次 × 最近购买」。

把免费层成本当成 CAC 看，而不是当成成本看
