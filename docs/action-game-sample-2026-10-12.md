# Language action task sample

## 2026-10-12 English-first correction

Visible chunk-bank correction: candidate buttons are always shown from first render, not only after typing a shared initial. Each sentence token has a separate chunk identity (including repeated words); authored distractors are additional buttons. The bank is alphabetically arranged rather than revealing sentence order. Clicking a chunk fills the active slot and advances; tokens used in other slots are dimmed/disabled until that slot is edited. Initial-key cycling remains available. This supplements, rather than replaces, the letter-count underscores and meaning-group annotations.

Initial-letter assembly follow-up: the action task uses `initials-engine.js` and `initials-view.js`, separate from the full-spelling practice component. All sentence words become selectable slots grouped under authored meaning annotations. Empty slots show one underscore per letter. Candidate vocabulary is scoped to the current sentence plus authored distractors; repeated initial cycles candidates, a different initial advances, Space/Enter confirms a slot, and Backspace clears/moves back. Adjacent words sharing an initial require confirmation to distinguish them from cycling. Clickable candidates support touch. Only a completely correct assembled sentence advances; the component maps target values back to the existing task transition. This is guided sentence assembly, not independent spelling mastery. Drafts preserve active slot and chosen words. Keyboard, native input events and IME are handled separately; original practice behavior and real learning records stay unchanged.

Continuous practice follow-up: removed the connected-call Chinese moral-choice node and its optional departure ending. The enough success transition now goes directly to the lend exercise; normal entry is borrow → enough → lend → completion. This is a content-graph change, with no word-specific renderer branch. Regression coverage asserts that enough immediately displays lend, no choice buttons or former prompt intervene, and pause/replay still work.

Meaning-group follow-up: authored `annotations` correspond to `exercise.parts`, not whitespace-delimited words. The renderer keeps each English group together with its Chinese meaning, e.g. `Can I` / 我能, blank / 借入, `your charger?` / 你的充电器. Validation rejects mismatched annotation counts. Existing token gloss metadata and unannotated practice rendering remain backward compatible; answer assembly/normalization is unchanged.

Follow-up word-aligned sentence: removed exercise prompt, whole-sentence Chinese translation and charger ownership status from the task UI. The action task opts into reusable annotated cloze rendering: each fixed word and blank has an authored Chinese gloss underneath, validated against the sentence token count. Blank inputs use a bottom border only; the sentence layout is unboxed. The older practice page keeps its default renderer appearance and behavior. The sentence wrapper remains semantic layout, not a visible container.

Follow-up simplification: removed the duplicate complete English example from the heading. The single sentence is now the inline cloze form, with its Chinese translation beside the task. Word and pronunciation action share one flex row; the action speaks only the current word, not the answer sentence. This changes the common renderer for every learning node, not a per-word exception.

Default entry now starts at the borrow expression, without a Chinese route-selection click. Each authored learning node provides word, pronunciation, meaning, English example and translation; the common renderer displays them before the scene and provides browser speech synthesis with an unavailable/error message. Deleted the visible sample label and route status. Legacy branch data remains isolated in the content graph; it is no longer the entry flow. ## Boundaries

- `landing/action-game-engine.js`: validated task graph, immutable state, action selection, cloze evaluation, declarative effects and earned-expression identifiers. No task-specific words or persistence.
- `landing/charger-quest.js`: authored scenario, alternative borrow/buy routes, permitted onward lending, accepted expressions, misunderstanding feedback and state effects.
- `landing/action-game-view.js`: DOM/controls, battery/connection visual state, session drafts, pause/resume, route reset, library switching. Phone presentation is this sample's scene adapter, not a universal scenario renderer.
- Existing sentence cloze engine/view is reused, not duplicated.

The sample has no timer punishment or wrong-route punishment. It only records expressions used in the current page; refreshing/leaving does not save the task, and completion does not mark mastery or call learning-write endpoints. Real course content, browser records, accounts and databases are untouched. Service-worker replacement defers while a task is active, including pauses and library visits.

The goal is to restore battery and contact the friend, not collect every expression. Either `borrow` or `buy` changes battery from 2% to 24% and records borrowed versus owned possession; `enough` connects the call. Onward lending is optional and explicitly permitted by the owner. The two endings list only expressions actually used in that route.

The shared theme supplies brown line/ink, warm paper, yellow and timber depth; the vocabulary shell retains its quiet garden background, paper frame and global navigation/account controls. The heading/library action sticks to the top and available session controls stick to the bottom; restart appears after starting, route reset after leaving arrival, and pause is hidden while paused or terminal. The scene always reuses a single illustrative borrow image; changing to a shop does not generate new shop artwork. Battery, connection and possession status carry the actual state consequences. Reduced-motion removes the phone transition without changing those consequences.

Only opening the task assigns its AVIF/WebP picture sources; revisits reuse them, with no image library precache or large-original fallback.
