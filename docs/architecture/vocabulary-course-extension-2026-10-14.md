# 可扩展词书基础：第一阶段

## 后续进展：单元会话与分练习证据（2026-10-14）

已接入详情/目录、真实单元开始与单元级续学。单元位置使用现有 `vocabularyResume` 实体中的独立 SHA-256 范围键；旧整本键保持不变，无新增表或批量迁移。单元结构变化明确拒绝原会话，不覆盖旧位置。首页继续学习保留单元与结构版本参数。待提交队列按单元分隔冲突范围。

现有操作新增可选 `unitId`、`structureRevision`、`practiceType`、`inputMode`；类型绑定开始会话，播放器变化建立新轮次。完成事件 JSON 记录类型、输入方式、单元、结构版本及练习版本，项目进度新增按类型统计；未注明输入方式的旧请求记为 null，不猜测。旧请求继续兼容。辅助练习保留既有掌握状态，但不产生新掌握证据；未实现的跟读/听写等服务端明确拒绝。

测试使用内存数据库和浏览器夹具，覆盖独立单元、版本错误、跨单元保存拒绝、旧位置保留、按类型统计、实际客户端类型提交及输入切换。真实词书未添加虚构单元，未写真实账号做测试。真实教材素材、安全追加发布器和其他播放器仍待实施。

以下原第一阶段记录为历史范围；其中“单元会话/分类型尚未实现”的描述以上述进展为准。

## 已实施的边界

课程内容、内容组织、练习任务、输入方式分开。`js/vocabulary-course-contract.js` 是浏览器与服务端共用的纯校验模块，不读写账号数据。新增课程以数据声明内容，不复制页面或新增单词 ID 分支。

- 词书索引保持 `schemaVersion: 1` 向后兼容。可选 `catalog` 包含 `description`、`coverUrl`、`facets`。分类字段与既有学习目录一致：人群、学段、年级、水平、目标、题材、考试、系列、教材版本、版次、册次。服务端将这些字段送入现有目录。
- 可选 `units` 为 `{unitId,title,itemIds}[]`，必须按词书原项目顺序完整分配，禁止重复、遗漏及跨书引用；`structureRevision` 是 `JSON.stringify(units)` 的 SHA-256。没有单元的旧词书保持平铺，不自动编造教材单元。
- 新教学项目可使用 `learning: {schemaVersion:1,guidedExpression:{schemaVersion:1,revision,steps}}`。每步为 `{prompt,answer,choices,field?}`；`revision` 为步骤 JSON 的 SHA-256。引导必须与原句及原答案字段一致，选项不可重复。项目自身 `contentRevision` 仍覆盖整个内容正文。
- 旧六词内置配置只是兼容层。声明了 `learning` 的项目按通用格式运行，不根据单词或项目 ID 猜题。新增字段无需替换六词原始 JSON 或修订号。
- 练习类型登记表只把现有句子填空与中文引导标记为实现；跟读、选词填空、词序拼块、听写为不可用，并明确原因。登记不代表已实现播放器或评分。语音播放不等于发音评价。
- 新增只读 `/api/wordbooks/:bookId/details`，返回书目及单元摘要，不包含全部题目正文或图片。

## 课程添加流程

当前新增工具 `scripts/validate-vocabulary-package.cjs` 是**只读预检**，不是导入或发布器：

`node scripts/validate-vocabulary-package.cjs <课程包目录> <资源根目录>`

课程包包含 `index.json` 与 `items/<itemId 的冒号替换为下划线>.json`。新制作词汇插画使用同一张完整 16:9 WebP 供宽屏与窄屏复用，不另做 AVIF 或手机版裁图；每张实际交付图严格小于 20,000 bytes。只读预检验证身份、引用、内容哈希、单元结构哈希、引导版本、原题一致性、素材存在性及图片格式/预算。共享教学项目必须引用一致版本；不同义项和语境不要仅按拼写合并。完成预检后仍需人工预览和发布；预检不会修改线上文件或数据库。已有课程及旧格式图片保持原样，不因新规范自动迁移或删除。

已有专用六词生成器不是通用追加器：不要用它写入真实课程库来添加新课程，否则可能覆盖索引。第一阶段没有运行该生成器，也没有改变真实索引、课程、学习记录、图片或备份。

## 后续实施顺序与约束

1. 内容包预览及安全的追加发布：版本冲突检查、保留旧包、事务性切换；任何真实内容迁移或覆盖前，按 AGENTS 创建可恢复备份并确认精确目标。
2. 词书详情与单元入口：目录分页、系列分组、单元按需读取。任意单元开始前先实现单元级会话，不能借用旧平铺续学字段绕过服务端位置检查。
3. 分练习记录：练习证据绑定账号、词书/单元、教学项目版本、练习类型/版本、输入方式、提示使用、评分来源及请求 ID。会话位置与掌握证据分离，后者不能由客户端自称通过。
4. 逐个接入其他播放器与对应服务端答案校验。Shift 仅在同一练习允许的输入方式间切换；听写不能切成选答案后仍作为听写成绩保存。
5. 熟悉、手动标记掌握、考试验证分开；原辅助练习完成继续不算掌握。新语境应用考试需另行制定题型、评分和证据规则。

上述后续事项**尚未实施**。当前保存仍沿用原 `vocabulary.complete` 和 `vocabulary.session`，没有新数据库表、数据迁移或按类型统计承诺。

## 验证与运行状态

`scripts/vocabulary-course-contract.test.cjs` 覆盖新增项目无硬编码接入、分类、单元完整性、重复选项、字段校验、能力禁用、版本和只读预检；图片边界使用新临时目录，19999 bytes 通过、20000 bytes 拒绝；新课程预检拒绝 AVIF 与独立手机版裁图。真实六词包只读预检为 1 本书、6 个项目、24 个图片引用（历史课程格式）；新建内容按每词一个共享 WebP 计数。

`scripts/guided-sentence-ui.test.cjs` 在隔离浏览器夹具中验证新增非 pilot 项目及旧六词流程。没有用真实账号做写入测试，也没有为测试重启本机 8787。静态前端修改可以由现有服务提供；新增服务端详情路由与校验需要下次授权启动/重启才会进入已运行进程。
