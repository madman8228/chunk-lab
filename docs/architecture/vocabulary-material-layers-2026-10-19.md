# 材料、词义、教学任务与课程编排分离

状态：制作模型、管理端快照、来源保留发布、详情材料读取和听写已接入并通过隔离测试；真实试点仍待内容与发布批准。本文件不是发布批准。

## 现象、根因和取舍

原场景草稿的项目内同时携带 word／meaning、exercise 和 unitId。足以运行练习，却不能单独追溯一个来源条目被哪些词义、任务和课程使用；直接复制课程容易形成多个不一致副本。

本轮在制作层建立固定版本引用，并适配回既有 WordbookDraft。没有在前端按英文拼写猜测关系，也没有改服务器来兼容不明确的材料格式。适合解决问题的位置是内容制作／校验层；正式接入时还需要服务端权限和引用校验，不能把这个本地校验器当成授权服务。

更简单的替代是沿用整本 JSON 复制；它对一个样例足够，但不能满足用户明确提出的跨课程复用要求。更复杂的全局词典、图数据库或新 CMS 不是当前必要条件。此版只增加离线制作模型、适配器、校验和两个编排示例。

## 已实施的边界

| 对象 | 身份与版本 | 职责 |
| --- | --- | --- |
| sources | sourceId＋revision，条目 entryId | 原始词头、释义、原文、来源位置；不混入新写例句 |
| senses | senseId＋revision | 一个明确词义和来源引用；同拼写可有多个义项，人工决定是否相同 |
| activities | itemId＋revision，固定 senseRef | 一种语境下的例句、翻译及练习配置；改变任务应另建任务，不复用旧成绩身份 |
| applications | materialId＋revision | 原创对话／短文，逐句显式引用词义；不绑定某一门课程 |
| courses | courseId＋revision | 单元、目标任务顺序、应用材料引用和人群／建议水平，不内嵌另一份材料正文 |
| 学习记录 | 不新增或改写 | 正式接入仍走原服务端任务／内容版本和操作回执；材料浏览不能冒充答题 |

版本采用递归排序对象键后的 SHA-256，数组保留原顺序。引用必须指定准确版本；内容变更不自动升级引用。同一库不保存一个编号的多个历史版本，第一版也没有“找不到旧版就用最新版”的回退。历史多版本仓库与有审核的升级工具属于后续接入。

教材来源预留严格字段：出版社、书名、版次、册次、单元、请求页；每条分别保存教材页与扫描页。校验器检查字段完整，不证明扫描内容正确或版权已获许可。本轮仅用原创旧草稿构建来源快照，没有读取或创建真实教材课程；测试中的教材信息完全为合成数据，“全一册”原样保留。

## 两个课程编排示例

`drafts/scene-wordbooks/borrow-things-v1/material-library-v1.json` 包含：

- 1 份原创词表来源快照，6 个明确词义，6 个教学任务，2 段对话、1 篇短文。
- 成人日常编排引用 6 项与 3 段材料。
- 基础入口编排选择 pen／borrow／umbrella 三项，不复制任务，不强行配上包含未选目标的对话。
- 第二个编排仅用于证明选择、排序和复用，不等于完成零基础教材或难度适配。两者都未通过内容／分级审核。
- 同一任务被两本书引用时，编译得到同一 itemId／内容版本；不同例句的任务使用另一 itemId，即使引用相同 senseRef。

新库是已有 `review.json` 的独立派生草稿，不移动、覆盖或删除原稿。再次执行创建命令遇到同名输出会拒绝；修改需另用版本化文件名。

## 草稿适配与当前实现边界

`previewCourse` 先校验整库，再根据显式引用构造原 WordbookDraft。词头和释义来自 sense，例句与练习来自 activity，单元和顺序来自 course。返回的 bindings 独立保留任务、词义及来源版本，applications 保留材料正文及引用。

文本编译结果包在 `vocabulary-course-review-preview` 草稿信封中，始终 `publishable:false`。不把 bindings 偷塞进当前不接受这些字段的生产 item。正式发布走下述来源保留协议，将完整关联单独耐久归档，不因草稿预览成功而自动发布。

当前支持原有任务配置和可选的课程听写音频配置；听写播放器及独立会话已实现，真实服务默认不开启。跟读、选词和词序拼块仍未实现。没有把词义 ID 用作通用掌握 ID；“知道一个词义”不自动证明该词的所有新语境任务通过。具体听写验收见 `docs/plans/word-dictation-delivery-2026-10-19.md`。

本阶段只接受空插图配置，不接受未经真实文件核验的路径。正式素材接入必须复用现有真实文件检查：每词一个共享 16:9 WebP，wide／mobile 同路径，严格小于 20,000 bytes，按需加载、完整展示、保留原稿。不默认生成 AVIF／手机裁图。

`node scripts/prepare-borrow-material-library.cjs drafts/scene-wordbooks/borrow-things-v1/review.json <新的版本化草稿路径>`

`node scripts/validate-vocabulary-materials.cjs drafts/scene-wordbooks/borrow-things-v1/material-library-v1.json`

- `node scripts/vocabulary-materials.test.cjs`：引用与版本、复用、不同义项／语境、教材元数据边界、原引擎兼容、旧稿不变。
- `node scripts/vocabulary-materials-cli.test.cjs`：全新临时目录，拒绝覆盖、失败不创建输出、只读校验。
- `node scripts/scene-wordbook-ui.test.cjs`：原六项加两种编排投影，在隔离浏览器中运行真实原组件，无 API 或保存请求。

没有迁移旧教材、课程或学习记录；没有清除原浏览器数据、改生产索引、调用真实账号或重启服务。当前无前端补丁，也无生产接口启用。

## 服务端草稿接入（2026-10-19）

已增加管理端材料库快照接口，不复用会丢失来源的扁平单词本存储。复用同一套材料模型校验，不另写前端兼容规则。

- `POST /api/admin/vocabulary-material-libraries/:libraryId`：请求 `{library,baseRevision}`。首次必须 `baseRevision:null`；后续必须匹配当前快照版本。只追加完整快照，内容未变不追加；拒绝把已存在的历史快照重新设为当前。
- `GET` 同一路径：读取当前完整草稿；可用 `?revision=<固定版本>` 读取历史快照。
- `GET` 同一路径加 `/history`：读取历史版本摘要。
- `POST` 同一路径加 `/preview`：请求 `{revision,courseId}`。固定材料库和课程版本后，用原编译器生成只读预览，含来源绑定和应用材料；始终 `publishable:false`。

所有接口使用现有 `adminOnly` 管理权限；没有普通账号端点，没有跨账号材料共享。当前是管理员共用的制作空间，不是假定每份快照有个人所有权。材料库之间也不会按拼写自动合并或解析跨库引用；本阶段只验证一个库内的固定依赖。这些边界必须在后续个人材料库或公开共享需求明确后再扩展。

完整来源、释义、任务、应用材料、课程编排保存在同一事务内。每次更新完整保留旧快照，代价是重复存储；当前单次上限 10,000,000 bytes。暂不为小规模草稿引入跨版本实体分表和回收机制。并发写入用事务内版本检查拒绝覆盖；失败不改变现有快照。

存储为主业务数据库同目录下独立的 `vocabulary-material-library.sqlite`。构造服务和读取不存在的库不会创建文件；首次有效保存才建库。不能只复制写入中的主文件。原始扫描件、图片原稿与课程归档仍应独立保留，本快照不能代替它们的备份。没有新增覆盖恢复端点。

隔离验收：`node server/vocabulary-material-library.test.js`。测试使用新临时目录和随机端口，覆盖权限、无效输入不建库、来源完整保存、固定版本预览、历史读取、并发版本冲突、失败回滚及重开持久化。不连接真实账号，不向线上导入或发布，不启动或切换真实服务。

草稿保存本身不是“课程已审核或可发布”。学习端详情材料页面已接入；个人账号材料共享和管理端材料编辑页面未实现，本阶段制作使用受保护接口与本地校验工具。

## 来源保留发布协议（已实现，未执行真实发布）

管理端增加上述材料库路径的 `/release/validate` 与 `/release/publish`。前者接收 `{revision,courseId,review,images}`；后者接收 `{preparation,fingerprint,confirmed:true}`，其中 preparation 即前者请求。接口复用现有 adminOnly，缺少明确确认、版本或指纹不一致均拒绝。不会因保存或预览自动调用发布。

review 必须包含与快照一致的 revision、content／level／assets／rights 四项 approved、reviewer 和 note；这是管理员作出的人工审核声明，不是机器证明自然度或图片语义。测试只使用隔离审核夹具，不更改真实草稿待审状态。

images 是按课程任务顺序排列的 `{itemId,url}` 映射。原始材料草稿仍不需要图片；交付图绑定在发布层。每个任务使用一个实际可识别的 16:9 WebP，小于 20,000 bytes，wide／mobile 同路径，文件内容摘要进入发布指纹，核验后文件变化需重新核验和确认。自动检查不替代人工图片语义审核。

发布由原追加式发布器完成，材料快照、固定引用、审核声明及交付图摘要作为 `materials.json` 与课程索引／任务一起在私有暂存目录写入、刷盘并原子公开。写入失败不出现半成品课程；不覆盖旧目录、主索引或学习记录。两门课程可引用相同编号且完全相同版本的任务；同编号不同版本仍拒绝，课程单元与续学范围保持独立。

新增 `GET /api/wordbooks/:bookId/materials` 只返回该课程已引用的对话／短文及词义展示信息，旧课程无材料返回空列表，个人课程沿用所有者认证。不会返回原始来源、未引用编排或私有审核声明。静态守卫拒绝直接下载发布目录下的 materials.json（含编码路径变体）；正式环境仍使用原有受保护的服务数据目录。这里的公开发布是明确的可见性选择，不支持将私人来源悄悄链接到公开课程。

隔离验收：`node server/vocabulary-material-release.test.js`，覆盖待审／旧审核拒绝、真实文件大小／格式、图片映射、文件变动、指纹／确认、权限、原子失败、来源归档、重开读取、共享任务、公开投影和静态保护；另跑原发布器、草稿库、静态守卫及部署依赖检查。当前未实施真实发布。

## 材料与课程备份覆盖

现有 `node server/backup-db.js backup` 在主库快照完成后，额外调用 `vocabulary-material-backup`；材料部分成功后才打印原 OK 标记。不存在材料库／发布课程时保持原行为，不新建空备份目录。没有运行过真实备份或真实恢复。

材料备份包含独立 SQLite 在线一致性快照、已原子发布的词书 manifest／items／materials、引用的交付图及封面。每个文件记录路径、大小和 SHA-256，复读校验后整体原子完成；共享图片只复制一次。材料图片须与归档中审核摘要一致。缺文件、内容改变、目录越界或核验失败均不报告成功，只清理本次新建暂存，不清理旧备份／原文件。备份目标不得指向源数据目录及其子目录。

材料备份不是所有账户、扫描原稿或全站内容的独立完整备份：账号仍在原主库快照，未引用的原稿另行归档；两类快照按调用顺序独立取得，不能宣称跨数据库同一事务时刻。已发布来源为不可变完整快照，因此归档不依赖草稿库恰好同时有最新行。当前已包含正式引用的听写音频，并按归档摘要核验；不包含未引用的原始录音库。

`node server/vocabulary-material-backup.test.js` 在新临时目录测试热 WAL、所有历史行、来源／交付图、共享图片去重、全新恢复目录重新读取、缺图／变更失败、旧备份保留、CLI 联动。`node scripts/deploy-safety.test.js` 的 37 项护栏同时通过。实际恢复到真实账号仍需针对目标的明确授权和事务保护。

## 学习方式可用性摘要

`server/services/vocabulary-practice-summary.js`从固定教学任务派生词书／单元的素材覆盖数量，不承担学习记录、课程来源、审核或服务开关。新发布器在既有原子发布目录内写入practices.json，绑定书及结构版本并核验摘要；备份同步包含此派生文件。不扩展原制作包或个人归档格式，也不重编译、覆盖已发布课程。

新课程详情读取该小摘要，无需逐项读词条及图片／音频。旧课程无摘要时仅首次只读、核对词条元数据，按固定版本缓存在内存，绝不自动回写旧归档；个人词书从经过账号授权的现有包内派生。公开详情只暴露计数，不暴露选项答案、来源审核或其他账号内容。计数按索引映射线性计算，避免每词再次扫描全部引用；万项／百单元夹具覆盖此约束。

前端入口还须同时满足服务能力开启和当前范围的正素材数量，显示真实覆盖比例，并携带unit／structureRevision进入原播放器。素材可用不等于所有题可用、课程已审核或已掌握；单元／整书及不同练习的保存仍走原独立范围与协议3，不因摘要另起保存系统。

模式登记用independent描述独立练习范围，用learningKey描述相应素材字段；摘要只统计实际配置，不把implemented或服务开关固化进课程数据。引擎后来实现时无需改写已有素材摘要，未开放时界面也不会因为有配置就显示可学习入口。保存服务以小型模式绑定表选择判分器和证据类型，其余游标、并发、账号和协议3流程共用；旧句子／引导范围键保持兼容。

## 跟读参考材料与未验证自报

readAloud配置独立指定word／sentence目标、逐字文本与固定示范音频引用，不要求依附dictation任务。共享音频只是同一不可变文件引用，不复制资产，也不能因拼写相同自动跨义项关联。草稿／材料／编译／发布来源／音频实际字节与摘要／个人归档／备份已接入；旧项目不增加字段、不改版本，真实内容不迁移。

跟读本机录音与课程示范不同：前者仅页面内存，不进入课程资产、备份或上传。纯report契约只描述用户确认的听示范／录音／回听，是unverified-self-report且assessment:false，绝非可判分答案。现有vocabulary.complete会更新辅助答题计数及汇总，不能将report作为它的“correct:true”判分器；实际自报保存仍待独立协议操作与非答对统计实现，再复用已有会话／队列／回执。当前implemented和服务能力未开放，不因素材覆盖数存在而上线入口。

后续自报协议已实现：`vocabulary.rehearse`复用会话／独立scope／事务／队列／回执，写入新增`vocabulary_practice_reports`事实表，不写原答题事件、进度或汇总；读取状态从该表派生rehearsal次数／不同词条数，明确未验证。无需复制同步系统或增加并行成绩表。相同轮次同词拒绝重复确认，历史有效轮次保留提交版本且不倒退新位置。SQLite备份／全新目录恢复纳入事实；播放器和新方式浏览器闭环尚待接入，真实开关保持默认关闭，见跟读实施计划。

共享播放器现已接入跟读独立组件，原词书壳层、读取、会话、队列和账号逻辑不分叉。示范音频仍是课程不可变素材；本机录音是页面内存临时媒体，暂停／退出丢弃，绝不导入素材库或提交到服务。实际回放范围只用于本次交互门槛，不能升级为服务端验证的发音证据。客户端只提交显式四项确认，断网排队和恢复与其他练习共用；原四方式游标和答题表保持不变。implemented:true表示引擎存在，不等于课程已审核或正式开关已开。
