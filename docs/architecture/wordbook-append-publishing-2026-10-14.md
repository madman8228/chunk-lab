# 词书只追加发布

本轮接入工作台的管理员服务端校验和明确确认发布，沿用现有紧凑界面与背景。不是自动发布器，未在真实课程库发布任何测试内容。

## 流程

先录入/导入草稿并试学，再点服务端校验。客户端准备的包由服务端重新验证：单本词书、内容与引导 SHA-256、单元分配、编号、例句/答案一致性、素材真实存在、路径不得逃逸，以及每个词汇插画严格小于 20000 bytes。服务端返回包指纹；任何编辑或继续试学都会取消确认，必须再次校验。管理员勾选核对声明，并在发布时确认具体标题和项目数。

两端接口 `/api/admin/wordbooks/validate` 和 `/api/admin/wordbooks/publish` 都使用原管理员鉴权。普通账号与未登录访问不能发布。服务端发布再次完整校验包、素材和当前编号，再核对指纹；不能通过改客户端按钮绕过。前端只把管理员凭据发往同源接口，不清理或替换用户登录数据。

## 资产保护

发布只接受新词书编号和新教学项目编号。既有编号一律拒绝，暂无覆盖、替换、删除或改版 API。新包写入独立目录：生产为实际数据库目录下的 `wordbook-publications`，不放在会被前端构建重写的目录；测试实例可指定隔离路径。应用内置索引和项目文件保持原样。

发布使用排他锁；先把清单与各项目写入私有 `.pending-*` 暂存目录并刷盘，然后原子移动为按词书编号哈希命名的最终目录。失败时只清理本次新建的暂存内容，不碰原课程；崩溃遗留暂存目录不对外可见，遗留锁不会被自动强行解除。新课程发布成功后，内容服务合并元数据目录；只按需读取项目正文，不把整个题库下载到浏览器。

运行备份需要同时保存 SQLite 及 `wordbook-publications` 目录；现有只备份数据库的工具不等于已备份这些文件。没有运行真实数据迁移或覆盖，也没有改变已有备份。未来版本更新应另行制定明确授权和恢复方案，不能放宽编号冲突规则来模拟覆盖。

## 验证与限制

`server/wordbook-publishing.test.js` 使用新临时目录和随机隔离端口：原索引/原项目字节不变、校验只读、未确认拒绝、编号冲突拒绝、19999/20000 bytes 边界、指纹变化拒绝、写入故障不可见且回滚、成功后目录可读、重建服务后可恢复，以及 HTTP 管理员权限门禁。

`scripts/wordbook-create-ui.test.cjs` 使用隔离浏览器与本地截获响应：录入/预览不写服务，确认前禁用发布，编辑取消确认，确认后只发一次发布请求；真实账号或课程库未参与测试。既有六词与规模测试回归通过。

素材上传器、真实教材内容、旧版改版/下架、自动备份这些发布目录和新练习播放器尚未实现。正式课程目前只能引用已安全部署到 assets 的素材。当前运行的服务是否更新，见本轮最终说明；不得把隔离测试通过称作真实课程已经发布。
