# 课程归属、复习与首页返回

普通课节练习在 main.html 的 startDeck 入口检查显式加入关系，未加入时返回课程目录，保留由用户点击“加入学习”的选择。到期复习的首页计数、队列和学习档案采用同一课程归属规则，只纳入已加入课程。退出课程只影响派生复习范围，不删除历史答题、错题或课程内容。

CourseEnrollment.deckMemberships 通过课程目录归属和加入记录生成只读查询，支持既有别名。首页错题 TOP 和学习档案错题列表显示课程名称及“已退出”或“未加入学习”。用户仍可主动查看和复习历史错题。

返回旧首页的直接原因是 main.html 的顶部 Home 和设置入口硬编码 https://jqka.top/，本地用户会跳到线上旧版本。两处改为当前站点 /index.html，线上和本地使用同一导航路径。已有 Service Worker 导航采用网络优先，本次重新生成缓存版本。

隔离验证：e2e/course-membership-review.test.js 使用新临时数据目录和独立端口，通过真实服务保存测试课程及历史答题，验证未加入/加入/退出时的复习变化、记录完整、未加入课程入口拦截、历史错题标签，以及 Home 保持当前站点并显示新版导航。course-enrollment-protocol3、课程加入存储测试、缓存和发布清单检查通过。没有操作真实课程记录或重启当前本地服务，尚未发布线上。
