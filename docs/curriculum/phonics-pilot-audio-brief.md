# m/s/a/t 拼读样板：声音交付清单

状态：2026-10-24，交互预览可用，专业声音材料待提供。不是请求用户自行编辑文件；录音人按本单即可交付候选，由开发侧完成格式、绑定和试听流程。

## 本批目标

中文母语成人、单一清晰美式示范。学习字母在受控词中的声音，不教授字母名称。教学词mat（垫子），首次迁移词sat（坐，sit的过去式；本课不教过去式变化）。迁移只检验已教音形对应，不要求学习者推导词义或语法。

## 必备录音

| 稳定素材名 | 示范内容 | 验收重点 |
|---|---|---|
| sound-m-v1 | /m/ | 双唇鼻音，可持续；不要加元音或读字母名称 |
| sound-s-v1 | /s/ | 清晰无声摩擦；不要读成字母S或带元音音节 |
| sound-a-short-v1 | /æ/ | 本课a的目标短元音；不是字母A名称，也不是/a/ |
| sound-t-v1 | /t/ | 清楚的塞音释放，不额外加“特/te/tə”；可提供重复的独立示范并声明每段位置 |
| mat-separated-v1 | /m/、/æ/、/t/ | 单独音顺序清楚，音素间留短间隔，结尾t不带元音 |
| mat-connected-v1 | 从延长m过渡到æ，末尾t，再自然读mat | 同一位示范者自然衔接，不机械拼接其他来源；提供声音对应时间点供核对后高亮 |

可另外补sat真人自然整词核对。当前sat已有Edge Jenny候选，未批准；mat已有上一轮批准的Edge整词。专业单音与这些词音的衔接和口音一致性需要一起试听，不因单音孤立听起来正确就自动通过。

## 制作与文件

- 优先保留无损原始录音；每条单独文件，另存浏览器交付音频，不覆盖原件。
- 注明示范者、口音、录音来源、使用授权和是否允许课程传播；付费或外部委托需负责人授权，不自行下单。
- 文件名与上表绑定；连续片段标注原始时间点，必须试听确认后再驱动逐音高亮，不能按字母数均分录音时长。
- 不用IPA字符串TTS、中文谐音、字母名称或整词裁剪冒充纯音。通过格式解码只证明文件可播放，不等于发音正确。
- 录音交付后先做hash/解码/时长检查，生成原生HTML试听页，逐条确认内容和听感；正式发布另行授权。
