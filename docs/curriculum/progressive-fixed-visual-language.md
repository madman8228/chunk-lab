# 渐进搭句固定视觉约定

2026-10-25。用户要求 I、You、like 等高频词固定为渐进课程专用素材，不再临时使用含义近似、人物不同或附带无关对象的图库场景。以下为执行方案；新图仍须视觉验收。

## 第一组：固定人物与基础含义

沿用用户此前批准的成人形象：A为深棕长发、绿色外套的成年女士，B为短棕发、芥末黄色上衣的成年男士。

| 素材 | 固定表达 | 必须避免 |
|---|---|---|
| I | A面向观察者，手指自己胸前；表示当前说话者 | 工作、读书或饮料等额外动作对象 |
| You | B面向说话者视点，B是唯一人物，用户修订要求去掉所有第一人称前景手臂 | 任何前景手臂、两名互指人物或其他完整人物 |
| like | 用户修订要求只用一颗独立的卡通大红心 | 人物、手势、书、咖啡、食物、动物；不表示like=像 |
| work | 用户修订要求卡通人物满头大汗、吃力搬砖，动作有动态感 | 办公文件、校园作业、work=作品；搬砖仅为工作的一种示例，不把work词义收窄为搬砖 |

I/You固定的是说话视角，本阶段用A说话、B听话以减少负担；后续换说话者时指代必须跟随角色变化，不把女性永久等同于I、男性永久等同于You。句法成分继续绑定当前句子，不写进图片永久含义。

## 复用与组合

- 单词图只表达该词的当前含义；词组和句子按当前完成的语义组合。I like coffee与You like coffee须复用同一喜欢约定与咖啡对象，只变化指代人物。
- 已批准的成人整句场景与专用词义图保持相同人物外貌和服装；新图未验收前不覆盖既有资产或全量替换课程。
- tea、coffee等对象先使用已经批准的固定对象文件；rest可复用已有成人A休息场景。PB03的happy、ready后续按同一人物规范制作或复核，不在首批混入待定形象。
- 后续he/she/we/they固定人物关系；want/need/like固定不同意愿关系；in/on/under固定参照关系。新增词按课程实际需要扩展，不预先生成整个词库。
- 一词多义分开登记；语法功能词采用关系与状态显示规则，不硬配物体图。

第一批四宫格顺序固定为左上I、右上You、左下like、右下work，单格完整16:9，无文字、无跨格元素。运行共享图库候选复核与精确批次预检后生成。仅对本目标记录“候选不适用”，保留原课程图及其批准状态；精确词义/阶段/风格的已有通过候选仍阻止重复生成。

母图、裁切原图、批次清单、预检计划和每张交付图的尺寸/字节数/哈希都留档。浏览器交付每词一个16:9 WebP，严格小于20,000字节，按需加载，桌面与手机同一路径。先让用户确认这一组具体候选，再接入正式学习预览并检查I/You与like组合的语义清晰度；此流程不涉及课程发布或账户数据。
