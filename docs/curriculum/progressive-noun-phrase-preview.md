# PB04 名词短语样课

日期：2026-10-24。状态：待审阅的独立预览，未发布到正式课程目录。

规则：[渐进搭句教学规则](progressive-sentence-building-rules.md)；地图位置：[PB04](progressive-sentence-building-map.md)。先修 PB02 的主谓宾关系，You 来自已有基础课。

## 主要目标

理解名词短语的内部结构与整个短语在句中的作用是两个层次。在 I need a red bag 中：red 修饰名词 bag，是定语；bag 是短语的中心名词；a red bag 整体回答需要什么，作宾语。

本课只把 a bag 作为一个物品表达引入，说明 a 在此表示一个；不要求同时掌握全部冠词规则，系统冠词与数量课属于 PB05。

## 显式学习路径

| 步骤 | 目标 | 动作与目的 |
| --- | --- | --- |
| 1 | a bag：一个包 | 单练名词短语 |
| 2 | I need：我需要 | 单练待补对象的局部 |
| 3 | I need a bag | 合并已有局部 |
| 4 | red：红色的 | 学习颜色词 |
| 5 | a bag → a red bag | 先问 red 说明哪个词，选择 bag 后加入 red，当场显示 red → bag 并解释定语 |
| 6 | I need a red bag | 用扩展后的短语作对象 |
| 7 | 基于该句讲解 | 高亮 a red bag 解释整体宾语，内部定语已在第 5 步引入 |
| 8 | blue：蓝色的 | 学习替换词 |
| 9 | I need a blue bag | 先选定语 red，再替换为 blue，其余词保持不变 |
| 10 | 整个宾语辨析 | 隐藏标签，区别 a blue bag 整体、bag 中心名词与 blue 修饰语 |
| 11 | 定语和中心名词识别 | 在 I need a red bag 中分别找 red 和 bag |
| 12 | You need a red bag | 复用既有人物替换，重新逐词搭建 |
| 13 | You need a blue bag | 隐藏历史英文和选词，独立文本重组 |

第 5 步只提供 a / red / bag，不能提前混入 I / need。后续整句范围中，定语与中心名词在内部一层标注，宾语横线覆盖 a 到 bag 的整个范围，不能只把 bag 标为整个宾语。

第 5 步为 insert-modifier 互动讲解：界面先显示 a bag 及词义，问 red 说明哪个词；选错 a 时解释“a 表示一个，红色的是包”；选对 bag 后将 red 加入，再紧贴结果显示“red（红色的）→ bag（包）”和定语命名。讲解发生在第一次扩展中，不把读概念段落留作练习后的补救。该环节有示范支架，不计为独立掌握。

词组讲解支持 focusWordIds，绑定本步连续词范围；不把多个词的讲解退化成只高亮中心词。未选齐时不提前显示整个宾语的标注。

## 交互与结果

沿用课程切换、局部/合并完成列表、成分替换、词性/作用辨析和独立文本检查。替换定位阶段仅由源词响应首字母，定位正确后由替换词响应，避免本例 blue 与 bag 都以 b 开头导致无法通过键盘完成替换。

收尾可忽略大小写、连续空白与常见句末标点；只接受已列入的目标表达，不自动判定任意同义改写。记录首次匹配、重试匹配与查看示例，不认定长期掌握，也不把打字当作口语证据。
