# 渐进搭句操作区位置稳定

用户确认适用于所有已打磨UI：词块选择容器不能随动态内容移动。

根因是黑板及显示区使用最小高度，较长讲解和标签能继续撑高；hidden 又移除区域占位。统一在预览共享布局解决，不逐课补高度。

黑板固定桌面201.6px、窄屏252px，内容过长允许内部滚动并预留滚动条宽度。两级显示区加入常驻布局容器，桌面160px+160px、窄屏150px+130px；内部内容隐藏不移除外层占位。显示区超出时内部滚动，避免重叠或裁掉不可访问的内容。取消切步 scrollIntoView，独立输入聚焦使用 preventScroll；不妨碍用户手动滚动页面。
