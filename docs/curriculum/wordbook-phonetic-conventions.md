# 单词本新增音标记法

本规则只约束新增或新修订的音标，不自动改写既有课程内容。

- 英式音标保留经过确认的教材原标；新增美式音标以 Cambridge Advanced Learner's Dictionary 的 US 整条读音为依据。
- 仅从同一词条的标准 UK/US pronunciation 项取值，不混用词典页面内其他学习词典版块的转写。
- 保留 IPA 音素、长音、主次重音及美式卷舌标记；仅去掉音节分隔点，以适配教材常见排版。不得全局替换近似符号或根据拼写推断口音差异。
- 多词表达应查完整词组的读音和重音。没有可靠整条来源时留空；不得把单词音标机械串接后标为词典转写。
- 专名、多读音、词义依赖读音的条目没有完成判定时，保留待补状态，不自行选择读音。
- 旁车审核清单记录来源 URL、词典版块、原始读音、显示值及审核状态。新增候选默认为未发布；来源核对不等于发布批准。

2026-10-26 首批采用五条教材问候语。这个小批次不代表 IPA-DICT 美式草稿或其他旧内容已按本规则统一。
