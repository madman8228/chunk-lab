# 成人零基础英语知识地图 v1

对象为中文母语成人。S0–S4是本项目内部课程阶段，用来组织先后和检查覆盖，不等同于CEFR证书或学习时长承诺。知识点机器清单及依赖以 `src/beginner-curriculum/knowledge-map.json` 为准；每项的状态区分已审素材、草稿和待制作。展示映射见 `legacy-map.json`，候选映射不是发布状态，也不会写入用户学习进度。

## 四条路线的职责

| 路线 | 学习者要获得的能力 | 不负责替代 |
|---|---|---|
| 情景表达 | 听懂熟悉生活中的短表达，回应并完成小任务 | 系统教授全部语法或发音规则 |
| 逐步搭句 | 从有意义的完整词块开始，逐步补充、替换、撤提示，独立造新句 | 纯粹拖词排序；已给答案的选择题不算独立表达 |
| 音标与发音 | 听辨常用英语声音，了解音标如何帮助查读音，模仿清晰表达 | 只读音标符号或用中文谐音代表真实发音 |
| 自然拼读 | 将已教的字母/字母组合映射用于合成、拆分和解码新词 | 规则覆盖所有英语拼写；自然拼读不能代替不规则高频词和词义学习 |

四路线共享词汇与知识ID，但练习证据分开记录。例如，正确选出声音不代表会发音；看着字母组装出单词不代表能读出新词；键盘输入不等于口语。

## 阶段与覆盖边界

| 阶段 | 交际及句子结构 | 声音与音标 | 拼读、读写 |
|---|---|---|---|
| S0 起步 | 学习指令、问候、姓名、求重复；用整块短语开口 | 区分字母名/词中声音；认识音标用途；开始常用音听辨 | 认字母，听音/口头音素意识准备，不要求先学完整音标表 |
| S1 短句 | I/you/he/she/it + am/is/are；指物、归属、基础单复数；表达简单需要 | 常用辅音、单元音、词尾音及易混音 | 常见单字母音、短元音、受控CVC拼合拆分 |
| S2 基础交流 | 喜好与Do问句、数量价格、时间日期、can请求、there be和位置 | 双音节词重音；保持可理解度 | sh/ch/th、辅音连缀、词尾e模式，单列常见例外 |
| S3 扩展表达 | 日常习惯/第三人称、频率、少量现在/过去/计划、and/but/because | 句重音、弱读、基础语调 | 常见元音组合、r相关模式、多音节初步、高频词缀与例外 |
| S4 综合使用 | 点单购物问路预约；简短多轮确认；表格、留言和简短阅读 | 在自然短句中迁移，需要时回专项补练 | 从受控词到短材料理解，能用音标/词典辅助不熟拼写 |

具体知识目标、前置与独立检查列在机器地图。被动语态、完成时、复杂从句不纳入S0–S2，也不因某个动词容易变形就提前堆在一节课。S3按使用需求逐步引入少量形式；更复杂内容留待后续课程。

## 单课怎样教

1. 先用情境、图片或声音建立意思，不要求用户预先认识英文文字。
2. 示范完整、自然、可直接使用的句子或声音。中间组装步骤是教学脚手架，不要把不自然的半句伪装成口语范例。
3. 每一步只引入一个主要新结构或声音对比；组装可先选完整词块，再补空、替换。
4. 逐步减少中文、图片和现成词块提示。最后用没出现过的词或新情境检验迁移。
5. 复习穿插旧知识。跟读自练如无真实语音分析只记“已尝试”，不标正确或发音达标。

## 制作与审核

候选课需记录目标知识ID、前置ID、首次引入词义、示范和独立检查。声音素材要能代表目标音；音标符号由真实录音/合格发音示范呈现，不能把符号文本交给TTS读出来充当音频。内容、声音、技术校验和系统发布各自审核、各自绑定文件摘要。未获得相应批准的内容保持草稿。

覆盖或状态更新需同时更新JSON、这份人读说明和测试。发布版本另存，不覆盖已发布课；旧课映射需要人工核对目标，不根据标题或相似课程自动推断。
