## Colors

沿用词书色族：普通文字使用 `--workspace-ink`（回退 `#523019`），提示使用 `--workspace-muted`（回退 `#745333`）；确认按钮继承蜂蜜色（`#ffe08a`，边框 `#ccad62`）。已选块使用既有悬停纸色（`#f4ead4`），分隔线为暖棕色（`#aa895c`）。错误时分隔线变红（`#ad3827`）、反馈为深红（`#893323`），同时提供中文说明与 `aria-invalid`，不只靠颜色传达。

这些是现有组件家族的实现值，不新增全局调色板。非错误反馈回到棕色文字；文本选区继承蜂蜜色底与棕字。

## Typography

词块是可选择的真实文本，按钮继承宿主字体，不引入字体或文字图片。每个词块标记 `lang="en"`，位置及操作标签使用中文。说明与反馈为 14px、行高 1.5，空排列提示为 16px；词块行高 1.5，长内容完整换行，不省略教学文本。

## Layout

表单顺序为简短说明、已选排列、待选词块、重新排列与确认、就地反馈。两区与操作行均可换行，间距 8px；已选区域最小高度 54px，以底部分隔线表达区域，不叠加卡片。操作行上距 16px。按钮最大宽度 100%，允许长英文块内部换行。

组件本身没有新断点，继承词书容器：宽屏场景与答题区左右排列，600px 及以下改为上下排列。四档隔离截图路径为 `output/playwright/chunk-order-component/{1440,774,390,320}.png`，由组件测试生成；本文未额外进行截图视觉审查，不把截图存在当作设备兼容结论。

## Components

### 交互与中文标签

待选词块初始化时打乱，点击后追加到已选排列末尾；点击已选块将其撤回待选区。待选区保持本次初始化的打乱顺序；“重新排列”清空所选，不重新随机洗牌。确认始终显式提交，选完最后一块不会自动提交。错误保留全部排列；下一次移动清除旧反馈与错误标记。

| 场景 | 实际文案或可访问名称 |
|---|---|
| 操作说明 | 按顺序选择词块组成句子；点已选词块可撤回。 |
| 分区名称 | 已选排列 / 待选词块 |
| 空排列 | 在下方选择词块 |
| 待选按钮 | 选择词块：{英文词块} |
| 已选按钮 | 第{当前位置}块：{英文词块}，点此撤回 |
| 操作按钮 | 重新排列 / 确认 |
| 清空后 | 已清空排列，请重新选择词块。 |
| 未用完词块 | 请用完所有词块，再确认。 |
| 顺序错误 | 词块顺序还不对，点已选词块撤回后重排。 |
| 正确完成 | 排列正确；这是辅助组句练习，不代表独立掌握。 |

### 原生键盘、焦点与状态

每块和重排操作使用原生 `button type="button"`，确认使用表单提交按钮。Enter/Space 激活原生按钮，Tab/Shift+Tab 走原生 DOM 焦点顺序；组件没有全局按键拦截、拖拽要求或方向键排序协议。移动后显式聚焦同一词块，即使它是待选区最后一块；重排后聚焦待选区第一块。错误确认后优先聚焦剩余待选块，否则聚焦已选区第一块。

两个区域使用具名 `role="group"`；表单通过 `aria-describedby` 关联说明与反馈。反馈为 `role="status"`、`aria-live="polite"`；错误另在已选区标记 `aria-invalid="true"`。源码具备这些语义，尚不能据此宣称所有读屏器都会以相同顺序播报。

### 生命周期与回调

`VocabularyChunkOrderView.create(item, {onComplete})` 先委托现有模型与句子引擎验证，再返回 `element`、`focus()`、`values()`、`stop()`、`destroy()`。每个实例为说明与反馈分配独立 ID。

- `values()` 返回 `{chunkIds:[...]}` 的数组副本，外部修改返回值不会改变当前排列。
- `stop()` 仅停止移动、重排与提交，保留内存排列；它不隐藏表单，也不主动禁用未完成控件。暂停显示、可操作区域及焦点转移仍是未来宿主控制器责任。
- `focus()` 恢复活动状态，并在未完成时聚焦第一个待选块，或已选区第一块。它不是持久化恢复接口。
- 正确确认后，先锁定完成状态并禁用全部按钮，再调用一次 `onComplete`。结果包括 `values`、`inputMode:'chunks'`、`practiceType:'chunk-order'`、活动 revision 和引擎原句。重复提交不能重复完成；禁用后焦点如何转向下一题仍需宿主集成验证。
- `destroy()` 可重复调用；停止活动、移除提交监听和点击处理器、禁用按钮，阻止后续完成。它不移除 DOM，移除或替换由宿主负责。

组件不保存分数、进度、学习记录或云端回执。一次完成回调不是成绩已保存、下一题已切换或复习调度已更新的证据。

### 身份与内容边界

源码词块 ID 是稳定身份，绝不重解释为位置；只有“第 N 块”的语音标签表示当前排列位置。UI 使用 ID 映射按钮与答案，不能按原始数组下标猜标准顺序，也不自动切词生成配置。模型要求明确编写的 2–24 块及完整标准顺序；相同可见文本的块交换后，只要完整使用各 ID 且重组句子符合模型规范化规则，仍可正确完成。

当前限制是单实例内存交互；跨题、退出恢复、课程入口与错误配置的用户级处理尚未由此组件解决。未来控制器必须保留原 ID 与 revision，不能把 UI 位置提交成身份。
