# 通用提示条：文字操作与复用审查

## 本轮交付

将“重试读取”改成同行文字链接式按钮：无底色、边框和大按钮留白，悬停仍不出现色块；保留 button 语义与键盘操作，因为这是执行动作而非跳转地址。手机自然换行，不再为重试固定占据整行。

新增 `js/notice-banner.js` 的 `NoticeBanner.create(options)`，自行安装一次共享样式，不依赖账号 API 或额外样式文件。组件挂载到视口顶部浮动的 `#noticeBannerRail`，不参与页面排版，因此不推动导航或主要内容；提示文字区域允许点击穿透，只有操作按钮接收点击。工作区仍负责条件变化、账号隔离与关闭后同条件不重现；组件只负责呈现、关闭及动作回调。没有将业务重试、权限验证或持久化逻辑搬入提示组件。

已接入：首页、我的内容、发现的工作区通知，以及 `main.html?view=stats` 的模块加载失败通知。旧的工作区提示构造和专用样式已移除。增加运行时脚本引用、离线哈希和部署清单，避免本地可用但发布漏文件。

## 使用方式

```js
document.getElementById('noticeBannerRail').replaceChildren(NoticeBanner.create({
  message: '内容暂未读取成功，已有内容保留。',
  actionLabel: '重试读取',
  onAction: retryRead,
  onDismiss: rememberDismissal
}));
```

`message` 按文本处理，不解析服务端 HTML。没有动作时省略 onAction；onDismiss 可选。调用方负责异步动作的错误处理和请求合并；组件关闭不取消请求。关闭时仅在焦点原本位于提示内的情况下，把焦点移回挂载区域的标题或区域自身。页面切换时清空 rail，不设置全局消息队列，也不持久保存关闭记录。

## 提示入口审查

检索前台 HTML／JS 的 alert、status、toast 与 warning 入口，并重点核对工作区、main、save-status、账号表单及冲突处理。以下是按用户任务的归类，不是全部页面的生产功能验收，也不表示所有候选已经迁移。

| 提示类别／位置 | 结论 | 本轮处理 |
| --- | --- | --- |
| 首页／我的内容／发现的读取警告 | 非阻断、可恢复、同一意图 | 共用组件，保留同条件关闭记忆 |
| main 的学习记录模块加载失败 | 非阻断、可重试 | 已接入，保留原加载失败锁和重试流程 |
| wordbook-intro／wordbook-details 等内容读取状态 | 读取错误可复用，加载中与空内容不应都变成悬浮警告 | 列为后续候选，未迁移 |
| courses／decks 的目录或课程读取失败 | 部分网络提醒可复用，但整页无可读内容时应保留页面恢复出口 | 列为后续候选，未迁移 |
| auth-ui 登录、验证码、字段校验 | 与当前表单及输入直接关联 | 保留表单内提示，不迁移 |
| save-status 保存队列、必须更新页面 | 具有保存安全和时序约束，不是普通可关闭警告 | 保留既有状态机与更新控件 |
| sync-resolution-ui 冲突处理、恢复工具 | 需要明确选择与数据保护 | 保留原对话流程，不迁移 |
| main 测评成绩未确认／答题保存失败 | 需要持续提示和特定恢复动作 | 保留，不允许用关闭提示掩盖未保存状态 |
| 个人中心会员核销、图片缓存、反馈结果 | 应在用户正在操作的区域反馈 | 保留内联提示；瞬时 toast 不等于持久警告 |
| course-create／content-studio／admin 编辑发布校验 | 多数字段或任务级问题，需要上下文定位 | 不做机械替换，需在各业务任务内再审查 |

## 验证

- 电脑／手机截图已成组检查，文字操作明显更紧凑。
- 首页 UI 测试通过：固定定位、课程坐标不变、重试、键盘关闭、焦点、同条件不重现、恢复后可再次出现、长文本无横向溢出。
- 新增断言：重试悬停仍透明、宽度不超过 80px；组件可独立挂载、样式仅安装一次、错误文本不作为 HTML 解析。
- 学习记录失败重试、重复进入、加载中切走、电脑／手机、菜单、输入焦点与目录请求预算测试通过。
- 测试夹具存在模拟读取错误时，先用真实关闭按钮关闭顶部警告再操作其下导航；不使用强制点击绕过覆盖层。
- SW 哈希、导航版本一致性及部署清单检查通过。此前已报告的原子离线包超预算问题未因此放宽限制或移除资源；它仍是独立待办。

界面设计技能用于沿用既有暖纸色视觉、限制抽象范围及批量视觉检查。没有修改真实数据、操作用户当前浏览器或重启服务。
