# 个人中心右侧抽屉

用户提供的个人中心截图是结构参考：账号位于上方，功能使用带图标的纵向菜单；具体表单进入后显示。本站继续使用已有暖白背景、文字颜色和 SVG 图标，不复制参考网站的品牌、二维码或未实现的排行榜。

## 页面与交互

- 首屏显示账号、学习设置、会员与体验、备份与恢复、图片缓存、反馈问题以及退出登录。全部课程、我的内容与学习记录保留在页面导航，不重复进入个人中心菜单。
- 学习设置、会员、备份、缓存各自使用独立视图。返回按钮保留本次打开期间尚未保存的设置。
- 只有学习设置显示保存和取消。沿用原有保存确认、失败提示与重试流程。
- 反馈使用原有子弹窗；关闭后回到抽屉并恢复焦点。Esc 关闭抽屉后返回页面入口。
- 原有控件和数据处理函数保持同一实例，通过移动 DOM 节点组织视图，不复制账号、会员、备份或缓存逻辑。

## 布局

- 桌面为右侧 304px 抽屉（按用户要求由 380px 收窄 20%）；540px 以下使用屏幕全宽。
- 抽屉高度跟随动态视口，标题和设置操作区固定，内容区独立滚动。
- 菜单行最小高度 46px，设置行最小高度 48px；按钮、开关支持可见的键盘焦点。
- 不在个人中心使用课程页面的插画背景；以暖白表面、克制的图标、留白建立层级。

## 实现与验证

- `main.html`：菜单和视图容器、既有设置及会员入口接线。
- `assets/personal-center.css`：限定在个人中心的抽屉样式。
- `js/personal-center-dialogs.js`：视图切换、控件重排及原有焦点管理。
- `scripts/personal-center-drawer-ui.test.cjs`：模拟账号的五种尺寸检查，以及随机独立端口、模拟 API 的完整页面加载检查。
- 设置保存与备份保护继续由现有隔离 VM 回归检查覆盖。验证不访问运行服务和真实账号。

本次不提交 Git、不部署、不修改课程或学习记录。旧的居中折叠式个人中心截图及对应布局断言不再是新版抽屉的视觉依据。
