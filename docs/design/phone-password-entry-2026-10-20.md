# 手机号登录与注册拆分

范围：共享 `auth-ui.js` 弹窗及手机号认证服务。保留现有木色、暖纸视觉，不改首页布局，不发送真实测试短信，不变更真实账号密码或课程记录。

- 默认登录仅显示手机号、密码，使用既有密码登录接口；不请求验证码，使用 current-password 自动填充。
- 独立注册入口显示验证码和必填密码，使用 register 验证目的。前端和后端都要求密码至少 6 位、最多 72 个 UTF-8 字节。已有手机号注册会被拒绝，不借注册流程覆盖其密码。
- “设置／找回密码”使用 reset 目的验证手机号，仅更新已存在账号的密码，不创建替代账号。历史验证码账号保留，原账号 ID 和学习记录不变。
- 保留已登录旧账号绑定手机号，以及受服务端开关控制的旧用户名登录入口。绑定不填密码时保留当前密码。
- 隐藏的验证码字段不参与焦点顺序和必填检查；提交中不可切换模式或重复提交。验证码的目的与发送手机号同时核对。
- 服务端保留旧客户端入口兼容；新的手机号注册即使走旧入口，也不能创建无密码账号。没有数据库迁移或账号批量改写。
