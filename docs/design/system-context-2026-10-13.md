# 全站功能与设计上下文

日期：2026-10-13。用途：后续 impeccable 设计的必读材料，而不是已批准的全站改版方案。
依据：用户明确要求、当前源文件与既有交付记录。代码存在不等于本轮对每个功能做了生产验收；本轮没有读取真实课程正文或修改用户数据。

## 产品事实

- 品牌 jqka.top；背单词、练句子同等核心，分别服务不同阶段，不强制先后顺序。
- 首页仅呈现本人相关学习内容，布局简洁。公共内容选择、个人管理、练习和学习档案应有明确边界。
- 图片中第三方课程、年级及教材示例不是本项目拥有的课程，也不是授权导入的资产。
- 年级、CEFR、目标、题材、教材版本是内容元数据；单词、句子、听力等是学习活动，不能混成同一层导航。

## 用户计划扩展（不是已交付功能）

语法练习、句型练习、系统跟读、听力训练、发音与音标；不同年级、学习阶段、题材、考试、行业以及教材版本内容。
不得用现有音频播放、例句或目录标签证明这些完整引擎已实现，也不得上线无可用内容的假入口。

## 内容与状态关系

- 内容身份：resourceId/courseId 与 sourceRefs 复用既有稳定引用；课程包含课节，词书包含学习项。
- 内容类别：课程、词书、教材。来源：内置、创建、导入。可见性：公共、私有。来源不能只由 private 推断。
- 个人状态：收藏、加入在学、学习进度、当前断点分别存储；收藏不是加入，加入不是拥有，退出不是删除。
- 同一导入课程可以已收藏且在学。筛选允许集合交叉，但页面不能因此把它误呈现为多个独立课程。
- 一段内容可支持多种练习方式；能力来自真实内容和引擎契约，不来自任意标签。
- 学段/版本/难度只能来自明确元数据，不能由标题猜测。缺失时保持未知。

## 已发现的设计欠账

1. 个人首页、个人学习库和 decks 的我的课程都有课程列表/续学入口；尚缺一套清晰的主入口与详情分工。
2. 在学/收藏是个人状态，创建/导入是来源；最近界面将它们作为同层分类，语义不统一。
3. 发现工作台与 decks 发现课程/市场也存在入口重叠。不能只合并个人页而忽略公共发现。
4. 当前 DESIGN.md 主要记录 landing 与词汇场景视觉，不是整个 main/decks/stats 的统一视觉合同；不要把它的局部规则无差别套到所有页面。
5. 旧 PRODUCT.md 偏句子训练与旧品牌，已根据用户确认的双核心定位补正；历史执行计划不是新的产品批准书。

## impeccable 能力与正确使用方式

本机技能版本4.3.1。它是代理读取的设计工作流程与检查工具，不是自动掌握业务的独立设计师。

| 能力组 | 命令/流程 | 在本项目的用途 |
|---|---|---|
| 产品与设计上下文 | init、document、extract | PRODUCT.md 记录产品事实；DESIGN.md 记录视觉体系；提取真实可复用组件。不能用视觉文档代替业务清单。 |
| 先规划 | shape、新工作流程 | 确定用户任务、页面边界、方案和验收后再实现。shape 本身只产出待确认设计简报。 |
| 评价 | critique、audit | 人工 UX/层级审视，以及可访问性、响应式与技术检查。detect 无发现不证明页面职责正确。 |
| 布局与减负 | layout、distill、quieter、clarify | 去重、建立主次、整理空间和文案；不是先把所有功能塞进卡片再换皮肤。 |
| 视觉表达 | typeset、colorize、bolder、delight、animate、overdrive | 排版、颜色、表现力与动效；应服从学习操作场景，不抢学习内容。 |
| 稳健性与交付 | adapt、harden、optimize、onboard、polish | 手机与键盘、长标题/空态/错误态、性能、首次使用与交付收尾。 |
| 交互比较与维护 | live、generate、context、detect、doctor、hooks、pin/unpin | 有依据地比较版本，加载上下文、扫描问题、检查文档漂移；不代表自动获知整个系统。craft 是旧别名，teach 是 init 别名。 |

推荐顺序：产品事实补齐 → 全站功能去重与职责图谱 → 页面简报确认 → 统一视觉合同 → 实现 → 桌面/手机/键盘及数据路径验收。
本轮只完成事实梳理与上下文补充，不触发 live 页面注入、数据库修改、界面改版或 DESIGN.md 覆盖。

## 后续设计的必读与验收门槛

1. 读取 PRODUCT.md、本文件、现有 DESIGN.md 的适用范围和对应页面源码。
2. 对每个拟新增 tab 回答：独立用户任务是什么？与哪些现有入口重叠？主操作和数据来源是什么？不能回答则不新增。
3. 给出当前/目标入口映射；明确旧功能是保留、移动、复用还是仅改表现，不以删页面代替整合。
4. 内容身份、权限、真实学习进度与回执继续由现有模型提供，不自建快照或新统计。
5. 分别验证访客、空账号、已有课程、收藏/在学交叉、私有内容、长标题、加载失败、离线和跨设备续学。
6. 测试用临时数据目录与隔离端口；不重启线上服务跑测试，不动真实课程、记录、浏览器数据、备份和原画。
7. 词汇插画每个实际浏览器文件严格小于20,000字节，按需加载；学习记录和原始素材保护优先于任何设计命令。
