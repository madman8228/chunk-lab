# 公共界面参数

2026-10-24：按站点所有者要求收敛过大的圆角。唯一数值来源是 `assets/ui-tokens.css`，页面样式和动态弹窗直接引用 CSS 变量。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `--ui-radius-sm` | 4px | 小标签、局部细节 |
| `--ui-radius-control` | 8px | 常规控件、封面 |
| `--ui-radius-card` | 10px | 课程卡片和列表卡片 |
| `--ui-radius-panel` | 12px | 大面板、弹窗、导航外框 |
| `--ui-radius-circle` | 50% | 圆形播放按钮、头像等 |
| `--ui-radius-pill` | 999px | 完整圆头的进度条等 |

四档普通圆角用于统一现有页面的尺寸层级，圆形与胶囊是明确的形状例外。直边、下划线以及仅底部圆角继续使用原有零值和多角写法，例如 `border-radius:0 0 var(--ui-radius-card) var(--ui-radius-card)`。

根目录正式页面在 head 中先加载公共参数；嵌套的静态内容页通过 `landing/site.css` 的 import 加载。动态创建的通知、登录窗口、统计页 Shadow DOM 和句子讲解也引用同一组变量。新增独立页面需要显式加载这个文件；不要复制一份参数，或在单个页面重新定义这些变量。

本次覆盖正式页面和它们的共享界面资源。草稿审阅页、历史教学预览、导出交付物及课程内容中的样式不在批量改写范围。既有颜色与字体参数仍由各主题管理，本轮只统一几何圆角。

修改参数后的验证：生成受影响的浏览器文件，运行构建一致性检查，然后用 `node scripts/gen-sw.js` 更新离线缓存版本。通过正常的“发现新版本 → 刷新”应用页面更新，不清空浏览器数据。
