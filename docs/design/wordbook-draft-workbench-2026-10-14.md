# 词书添加工作台：草稿与只读试学

页面为 `wordbook-create.html`，从发现页“词书 → 添加词书”及词书详情入口进入。沿用 Impeccable 的紧凑表单、清晰状态与现有首页天空花园，不复制参考网站的大卡片或模式弹窗。

已实现：词书名称和主要教材分类、独立单元、教学项目录入/编辑、显式 `[答案]` 填空、中文引导行、草稿 JSON 导入/下载、结构校验、当前项目文字试学、带内容/练习/单元版本的待发布 JSON 导出。项目和词书生成独立编号；更改高级导入项目不会静默丢弃多个答案、反馈或标注，改用草稿文件编辑。

草稿只在当前页面内存，不自动保存到 localStorage、数据库或账号。离开有未保存提醒，必须下载并确认文件保存。导入新草稿会替换页面内存，所以未保存时必须确认；已发布内容包不能冒充草稿导入。试学不发送请求、不下载整库素材，也不写练习记录。导入限制 10 MB、10000 项、1000 单元；列表只呈现最近 20 项，完整草稿保留在导出文件。

**尚未实现正式发布器**，按钮明确禁用。导出的 `wordbook-prepared-package` 包含 `index` 与 `items`，标识 `published:false`、`assetVerification:pending`；不是已有目录式内容包，也不能直接投入线上。还需将候选包在隔离暂存区转换为目录式包，并运行已有服务端只读校验，检查资源真实存在、每个词汇插画严格小于 20000 bytes、编号冲突与内容版本；再实现预览确认及安全追加发布。这些未完成前不允许把本工作台称为完整发布流程。

未提供真实课程素材，不生成或发布伪教材、示范词书也未被改写。没有覆盖索引、课程包、图片、数据库或学习记录。任何未来真实覆盖/迁移都须按 AGENTS 保护规则执行。
