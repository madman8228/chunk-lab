# 词书听句认词页：用户参考图改版

范围仅为 wordbook.html 中教材默认听句认词模式。按用户提供的紧凑顶栏、居中学习卡、图片占位区、句子辅助操作及底部导航参考实施；保留现有天空、太阳和花草背景。

- 顶栏集中返回、教材/单元、离线状态、自动播放和真实词条进度。离线状态显示简短标签，完整说明保留在 title。
- 图片在点击高亮词后创建，关闭时保留占位，避免句子跳动。图片完整显示，中文释义顶部居中、台词在图片底部。
- 句子居中显示；音标区常显，缺失显示“音标待补充”，不编造课程数据。朗读按钮复用现有音频；翻译按钮展开/收起课程原有译文。
- 上一词/下一词仅改变当前浏览位置，不改写答题进度。首词禁用上一词。
- 用户追加要求后，底部中间加入当前词条收藏和 0.5/0.75/1/1.25/1.5/2 倍速选择。收藏复用 workspace.select、账号快照和离线队列，只保存 bookId 与 itemId 引用，支持取消和跨设备同步。倍速作用于真实 Audio.playbackRate，包含自动播放、手动重播及正在播放的音频；切词保留本页选择，刷新恢复 1 倍。
- 样式限制在 recognition-page，其他练习方式和账号记录不变。

验证：scripts/listen-word-ui.test.cjs 覆盖翻译、音标、上一词、下一词、图片延迟加载/不跳动、自动播放偏好、1024/390 宽度和零学习写入。e2e/grade9-whole-book-launch.test.cjs 使用当前课程隔离副本覆盖浏览与断网刷新，截图位于 output/playwright/wordbook-redesign。

按用户参考保留卡片顶部细黄色强调和独立的蓝灰辅助信息色；检测器关于圆角强调边及超出全站旧 token 的提示属于本页明确的参考图选择，不代表重新定义其他页面视觉体系。背景源文件未修改。
