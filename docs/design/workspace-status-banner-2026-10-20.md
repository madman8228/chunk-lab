# 工作区顶部可关闭提示条

用户参考：https://namethatui.com/web/alert-callout-banner 。沿用本站暖纸色与棕色文字，把原内容流中的 workspace-notice 改为视口顶部窄悬浮提示，不修改提示所描述的后台业务。用户反馈提示不应推动导航，因此采用 fixed 定位、不参与排版；条幅压在导航文字上方的空白边缘，文字区域点击穿透，只有操作按钮拦截点击。

## 行为

- 首页、我的内容、发现复用同一个提示渲染函数与样式；顶部提示不占布局空间，提示出现／关闭均不推动导航或课程。
- 警示图形、文字、按需显示的重试操作与可访问名称为“关闭提示”的按钮。动态内容使用礼貌的 status 区域，不使用页头 landmark 的 banner 角色，也不自动抢焦点。
- 同一页面、账号及相同条件关闭后，后台重绘不会使其立即重现；条件改变、条件解除后再次出现，或账号归属改变时重新显示。关闭只影响本次页面的显示，不写入账号设置、不停止后台恢复。切换页面时清空提示区，避免上一页的提示残留。
- 非自动消失的浮层；长文字可换行、限制高度并可滚动。手机上将重试放到下一行，保留 44px 触控目标。关闭后焦点回到页面标题，不滚动页面。
- 提示使用窄边框、轻底色、无阴影和小号文字；重试仍为文字操作，触屏关闭按钮保留较大点击区域。

## 验证

扩展 learning-workspace-home-ui.test.cjs：856px 与 390px 下，对比提示前后及关闭后的课程 y 坐标一致；验证提示在预留区内、重试、键盘关闭、关闭后的焦点、同条件重绘抑制、新条件显示、恢复后的再次提示与长文不横向溢出。此前 fixed 样式的截图不再代表当前状态。

原有首页多视口、输入焦点、内容菜单与目录请求预算测试通过，部署清单与 SW 哈希检查通过。界面设计技能用于保留既有视觉与限定检查轮次；浏览器自动化只操作新建的隔离页面。
