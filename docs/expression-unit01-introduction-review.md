## 建议课程简介

适合刚开始学英语、希望从简单交流入手的学习者。通过五个单元，练习听懂基本学习指令、打招呼与告别、没听清时请求重复、请对方说慢一点，以及听辨姓名拼写。每个单元包含示范音频、听力选择和简短英文输入；可以按顺序学习，中途退出后继续上次的位置。

## 学习顺序

1. 听懂基本操作：听到 Listen、Look、Start，知道现在该做什么。
2. 打招呼与告别：在见面和离开时，选择合适的简单问候或告别。
3. 没听清时请求重复：使用 Again, please. 请对方再说一次。
4. 请说慢一点：请求对方放慢语速，并与请求重复区分。
5. 听辨姓名拼写：听辨姓名 Lin、Ben 及逐字母拼写。
