# 词汇配图审核工作台

入口：管理员登录 `content-studio.html`，选择“配图审核”。复用现有管理员身份，不对普通学习导航增加管理入口。

## 本次范围

读取 `output/textbook-extractions/highschool-pep-required{1,2,3}-2019-20261016` 中的批次清单；兼容 panels 中的词头与 items 中的交付路径分开记录。第一册 326 项、第二册 349 项、第三册 393 项。单元按教材顺序展示，Welcome Unit 优先。后续教材需要在服务的课程目录适配器中注册来源。

每页24项，图片懒加载并完整缩放。支持教材/单元/审核状态筛选、关键词搜索、逐图放大、上一词/下一词、通过、需要修改、意见、批量通过、撤销上次操作、服务器断点和 JSON 问题清单导出。新旧审核版本可并排对照。

现有三册清单没有中文释义，页面明确显示“释义待补充”。审核者可填写补充释义，单独标明其来源，缺释义或文件检查有问题时禁止通过。当前功能不批量编造教材释义。

## 保存与版本

使用独立的 `illustration-review.sqlite`，与运行应用主数据库在同一数据目录，启用 WAL。仅保存审核记录、历史及继续审核位置；不修改源清单、图片、课程或学习记录。备份时须使用 SQLite 一致性备份机制，不能仅复制活动中的主文件。

审核绑定词条 ID、交付路径和文件 SHA-256。文件变化后当前审核回到待审，旧记录保留。写入检查 baseRevision，批量操作在事务内执行，冲突整批回滚。刷新失败不会显示成功，弹窗内意见保留；切换词条及关闭弹窗会保存已编辑意见。

服务接口均复用 adminOnly：GET `/api/admin/illustration-review`、GET/PUT `/api/admin/illustration-review/:course`。课程路径由目录白名单解析，图片限制在 assets 的真实路径内；核对 WebP 文件头、实际文件字节数严格小于20000及共享路径。用户审核通过不等于课程发布。

## 批量勾选状态修复

保存审核意见和撤销操作会替换卡片DOM；旧实现只从复选框DOM读取选择，重绘后丢失全部勾选。现在按教材、词条ID、图片/释义版本单独保存选择，并用专用sessionStorage键保存当前标签页的选择。卡片重绘、翻页、筛选、刷新及换书均可恢复对应选择；图片或释义版本变化时不会误选新版本。顶部批量按钮显示当前筛选范围的选中数量，隐藏于其他筛选范围的词条不参与本次批量操作。

隔离浏览器回归覆盖：勾选3项→其中一项填写问题并保存→关闭仍选中3项；另一项关闭时自动保存→仍保留3项；撤销、跨页勾选、搜索过滤、刷新恢复和换书隔离均通过。此修复只保存勾选界面状态，不改写既有审核结论或学习记录。

## 审核操作栏

按用户反馈删除标题下说明。统计、继续审核、批量通过、问题导出和撤销保留在同一吸顶操作栏内；桌面跟随审核区域滚动，手机位于固定导航下方，导航高度由ResizeObserver跟踪。保存状态改为“审核已保存”，与统计并排，不再用独立段落预留高度。浏览器测试覆盖925px及390px向下滚动后批量按钮仍在可视区域，并保留既有勾选及保存回归测试。

## 审核后即时筛选

保存和撤销后重新应用当前单元、状态及关键词筛选。未审核筛选下通过的卡片立即移出，批量通过一致；已通过筛选下改为有问题也立即移出。其他符合筛选的勾选保留，撤销可恢复卡片。若弹窗当前词条移出筛选结果，关闭弹窗，避免旧下标指向另一词。新增上述单项、批量、撤销和弹窗回归测试，均使用隔离数据通过。

## 单卡片保存反馈

单项审核不再调用全区域禁用：仅操作中的卡片显示“保存中…”，其余卡片可以继续点击。不同词条连续操作进入串行保存队列，等待项显示“等待保存…”，执行时读取最新审核revision，避免返回整本数据时互相覆盖。保存期间暂时锁定换书、筛选、批量和撤销等上下文操作。刷新列表按词条ID复用未改变的卡片节点；后台保存其他词条时不重置当前弹窗未保存意见。

隔离浏览器测试人为阻塞首个PUT，验证其他卡片仍可操作、第二项排队且最终两项都保存、未变更按钮节点保持连接；模拟503后目标卡片恢复可重试，其他按钮不受影响。既有勾选、即时筛选、弹窗、吸顶及手机布局测试同时通过。

## 问题卡片辨识

状态为changes的卡片使用红色整框、浅红文字区和白字红底“需要修改”标记；在已有紧凑布局下显示一行问题类型/意见摘要，完整意见保留于弹窗。操作文案改为“查看问题”。通过状态使用绿色文字，待审保持中性。仍按当前状态筛选展示，不修改既有审核结论。隔离测试验证问题标记、摘要、按钮文案及区别于普通卡片的边框样式。
