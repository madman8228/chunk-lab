# 工作台入口修复

显式 view=home/my-learning/discover 曾被归类为需要等待学习启动的入口，阻止本地首屏；完整启动时又会先消费旧学习跳转。结果可能显示空课程名和加载中的练习框。

修复：工作台入口允许本地首屏，完整启动优先回到指定工作台；保留真正的课程/课节、测评和复习入口优先级，不清理课程、学习记录或浏览器数据。

隔离浏览器回归先观察到“我的内容不可见”的失败，修复后通过。课程启动回归和生命周期测试仍通过。真实浏览器重新加载后恢复五条个人内容的显示。

此前个人单词本链路的开发仍是未上线的工作：新接口、追加版本与账号隔离已在临时数据库和隔离端口测试，运行中的后端没有重启。后续需继续完成版本追加后续学和备份恢复验收，再决定启用；不能把制作按钮的出现当成后端已启用。
