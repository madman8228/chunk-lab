# 已学完课程入口

## 完成判定

- 句子课节：索引已读取、有效内容数大于零，且已练数量与总数相等。显示百分比不能作为完成依据；尚差内容时最多显示99%。
- 故事课节：只认明确的completed或completedAt；seen表示学习过，不能证明学完。
- 课程：全部课节均有可核实的完整覆盖才显示已学完。空课程、不可用课节和未接入的内容类型保持未知。
- 单词本：复用现有服务端practice-coverage-v1投影和分页接口，不增加持久化完成标记；旧版本学完而当前版本有新增内容时显示“曾学完 · 有新内容待补学”。
- 已学完代表覆盖，不代表掌握。句子和故事不依据当前记录推断无法核实的旧版本完成时间；受保护课程尚无完整覆盖投影时保持未知。

## 页面

- 我的内容增加已学完数量和筛选；已学完课程提供再次学习及学习记录入口。
- 首页未学完课程保持在当前在学，学完课程进入可展开区域。已有加入状态保持不变，复习安排继续使用原逻辑。
- 完成查询按账号隔离；失败时保留已有元数据并提示列表可能不完整，提供重试，不将旧缓存当作最新确认状态。
- 统计读取课程目录、学习记录和索引，不预加载词汇图片。

## 验证

- course-progress.test.js：完成、空课程、索引未知、故事部分阅读。
- scripts/main-deck-progress.test.mjs：199/200保持99%，不得提前学完。
- scripts/main-course-navigation.test.mjs：续学选择。
- scripts/course-completion-runtime.test.cjs：分页、读取失败、学习变化刷新、账号隔离。
- server/services/vocabulary-course-progress.test.js：追加内容、版本、单元和账号隔离；仅内存数据库。
- 本地实际页面验证已学完筛选、数量与空态；原课程和学习记录未改写。
