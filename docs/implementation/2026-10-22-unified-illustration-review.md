# 统一配图审核入口

配图审核后端不再只列高中三册。当前统一清单包括共享目录中的21册（小学16、初中5）及原高中3册，共24册。页面支持学段、教材、单元、审核状态和词义搜索；卡片仍分页显示，图片按需加载。

共享目录采用 `output/vocabulary-illustrations/catalog-20261022-reviewed-v1.json`，可通过服务配置 `VOCAB_IMAGE_CATALOG` 指定其他已核验目录。目录记录的原配图审批和共用审批在文件哈希、大小、WebP格式匹配时沿用；缺失、摘要变化及超20000 bytes的文件不能通过审核。新增入口不覆盖原目录或已有图片。

小学和初中采用独立的 `catalog-v1` 审核版本，绑定 sourceKey、词头、释义与当前图片哈希。高中沿用原版本算法。统一页面继续使用原 `illustration-review.sqlite` 的 reviews/history/cursor 表；新操作追加当前版本记录，历史保留，无数据迁移。已有通过结论在没有匹配的逐条覆盖记录时直接读取，不批量写入数据库，也不把图片共用审批当作例句或课程发布批准。

`scripts/lib/textbook-production.cjs` 通过同一个版本计算函数只读读取逐图覆盖结论。因此在统一页面标记待修改或撤销通过后，下一次生产核验会识别到相同词条图片的状态，阻止其被视为可发布素材；同图在其他教材中的审核状态不自动连带改变。该机制不撤下已发布课程，也不修改学习记录。生产工作台已有快照需点击“重新核验”刷新。

“教材草稿”当前仍是高中三册专用预览，调用统一目录时显式选择高中，避免把新增教材误标成高中草稿。
