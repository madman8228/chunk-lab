# 词书单元离线学习

## 行为与边界

- 公开词书进入单元时读取完整文字和练习，校验包与每个词条的 SHA-256 后，以单个 IndexedDB 事务保存。
- 独立内容库 `chunklab-vocabulary-content-v1` 按服务地址、课程、单元、结构版本存储；不存账号、token 或学习记录。
- 已存单元优先显示；后台下载完整新包后替换本机副本，当前页面继续使用打开时的版本。更新失败保留旧包。
- 个人词书暂用原读取路径；其他课程类型沿用各自内容仓库。
- 图片和音频仅在实际请求后缓存，独立媒体缓存最多 64 条、单条至多 1,000,000 字节。缓存可被浏览器回收，未缓存素材提供提示，文字学习可继续。
- 进入本账号已经联网确认过学习位置的单元后，断网可继续答题。本机队列仍使用原始 requestId、账号及服务范围；浏览器重启后从已确认位置与未同步操作恢复。
- 离线跳过需联网确认；新账号尚未确认过的学习位置不能凭公共课程缓存推断。
- 学习状态请求的明确 HTTP 拒绝不回退缓存；离线学习启动仍须满足已有确认缓存的身份与协议检查。
- 课程缓存写失败时允许当前页面使用已下载内容，但明确提示离线保存失败。

## 服务端

新增 `GET /api/wordbooks/:bookId/offline-unit`，有单元时携带 unitId 和 structureRevision。只提供当前学习范围的内容和已有版本摘要，不下载媒体正文。

读取明确内容版本时，当前版本命中即可返回；只有旧版本或未指定版本时才扫描历史。保留无版本歧义拒绝，避免每读一个当前词条重复校验全部历史版本。
