# 发布链路去重与反馈

范围：后台整本教材发布，保留现有同步发布协议，不新增任务队列。

一次发布原先在导入服务内执行两次相同的 publisher.validate，最终 publisher.publish / publishRevision 再独立复核。现在前置校验一次，复用它的课程包指纹；素材提升后仍由最终发布器独立校验。请求内 packageReader 对每个 URL 只读一次，不跨请求缓存；素材提升仍重新读取摘要，最终发布仍读取已安装文件。审核绑定、授权、问题阻塞、发布锁、逐文件 fsync 和原子提交不变。

界面在确认后立即禁用按钮并显示“发布中…”，顶部提示先保存审核结论，再核验与安全写入；失败恢复按钮并给出错误。提示不承诺虚假的百分比或后台阶段进度。

隔离测试：server/admin-wordbook-review-budget.test.js 修复前能捕获两次前置校验；修复后一次，共享音频夹具媒体读取预算不超过 8 次；保留篡改拒绝检查。e2e/admin-wordbook-publication.test.cjs 挂起发布请求验证忙碌状态及桌面/手机截图，然后完成真实隔离发布和学习记录回归。

限制：同步全量校验和逐文件安全落盘仍会阻塞服务主线程，未声称完全消除卡顿。若整本实测仍超预算，下一步应将整个发布操作迁入独立执行进程并提供持久任务状态，不能只把同步函数包装成 Promise，也不能取消落盘或终审来换速度。此文中的隔离夹具耗时不代表真实教材耗时。
