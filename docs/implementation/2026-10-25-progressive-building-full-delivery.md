1. 本次“全部”指知识地图 50 节点的有边界文字预览首版。学校语法为一致分析口径；广节点拆子课，不以 50 道题、50 个标签或随机拼句代替覆盖。

3. 新概念在第一次参与示范搭建时，就用当前句子的角色关系引出；然后才要求按名称选取/替换。长概念段落不能是唯一讲解途径。
4. 允许在示范和理解任务显示正在分析的英文；在独立输出和延迟检查中，历史英文、目标答案、成分标签及同题参考必须从活动 DOM 与无障碍树移除。

6. 多课共享可复用活动能力；只有实际课程需要时才增加能力，不制作可视化编课器、任意语法解析器或自动造句平台。

### 内容身份与版本

新契约 `schemaVersion: progressive-building/3`：

- `KnowledgeNode`：PBxx、子目标 ID、先修节点、课 ID、状态；本计划表中 a/b 等展开为 `PB05.a` 这类稳定 ID。
- `Lesson`：稳定 `id/version`、单一主要新目标、复用目标、先修、场景、词汇支架、步骤、迁移/复习规格。目录依赖是学习建议，不借此更改账号权限或阻止用户检查预览。
- `Token`：每次出现的独立 `id`、`text`、`kind: word|punctuation`，可选词元、词性、词形、义项。两个 the 或两个相同拼写保持不同出现项。旧词典上永久 role 不作为新句角色来源。
- `Step`：稳定 ID、`activity`、`phase`、教学意图、中文提示、context、显式 source/target/bank 出现项、依赖步骤、讲解焦点/关系、标注与验收。phase 为 introduction/practice/transfer/delayed-review。
- 不要求所有单词只属于一个永久语义组，不从 group 的固定前缀推导每步 target，不再要求 transfer 只能在整课最后出现一次。
- 标点是独立、不可被当作词汇选项的项目；基础排序完成时按作者目标显示，标点专项中显式操作。大小写与缩写按目标/已审答案管理，允许 `can't`、`you're`，不继续使用纯字母正则作为完整语言契约。

### 成分与讲解

- `SyntaxNode {id, role, segments: TokenId[][], parentId?, headIds?, modifiesIds?, level, explanation?}`。每个 segment 必须在该步目标中有序连续；多段可表示不连续成分，各段各画横线并用相同角色标识。
- 同层不得错误交叉或重叠，父子范围必须包容且无环；从句内外分层，角色与词性明确区分。两段之间的其他词不得被错误归入该成分。
- 支持整个短语选取/替换：先点/键选范围起止，再确认；不连续选择采用显式追加范围操作。检查身份与覆盖范围，不能仅比较中心名词。
- 新课使用简短上下文示范：如 red 修饰 bag、to learn English 整体作宾语、am 连接主语与状态；错误反馈解释当前关系。数据记录首次引入步骤，校验其在依赖该概念的具名练习之前。
- 词义、音形及旧知识没学过时给局部支架；不能把陌生词失败记录成句法不懂。

### 活动与变换

保留 compose/teach/replace/identify/classify/insert-modifier/quantity/transfer 的既有表现，由适配映射到共享运行事件。新增能力限于下列具体课程需要：

1. `context-choice`：显式场景中的已知指称、数量/可数性等；内容给出人物知道什么，不开发世界模拟器。
2. `range-identify`：选择完整多词成分，并在操作时解释其作用。
3. `transform`：在 source 上执行作者审核的 insert/delete/move/replace 操作列表。引用出现项身份及稳定插入锚点，不依赖前一次操作后失效的旧数组下标。允许多词范围和已审词形选项；不自动猜英语变位。
4. `time-relation`：用少量带意义的事件卡识别先后/持续/当前联系，再操作动词表达；不是只看 yesterday 猜名称。
5. `independent-output` 与 `delayed-review`：不显示同题英文历史；用已审答案及可解释规则评价，独立证据区别于练习。

事务内中间结果可以是待调整状态，例如 two bag、did worked；明显标出尚未完成，不计成功、不进入正确轨迹。只有完整目标匹配且教学指定修改都完成才能继续；错误尝试不能覆盖最后一次正确基准。Backspace 撤回本次已完成编辑，Esc 取消未确认的范围/候选。

既有语义轨迹要保留“局部 → 合并 → 扩展”的完成表达，而非把所有教学/测验步骤都重复列成句子历史。独立检查中临时隐藏，回看时再恢复。

### 键盘与输入法：具体决策

- 普通词块选前高亮真实首字母，不显示数字快捷键。唯一候选按字母立即选；同首字母存在多候选时，首次按键浮起首候选，再按同字母循环，Enter 确认。仅跳过真正不可选的出现项，不能按目标答案偷偷选中。
- Enter 优先确认待选词/范围，其次提交当前题，最后才是下一步；不得一次按键跨两个教学阶段。
- Esc 取消待选；Backspace 撤回。鼠标/触控走同一事件，不依赖拖拽。浮起有静态焦点样式，尊重 reduced-motion。
- 词形对比活动可保留当前 b/s 这类差异字母，但必须在实际字形上标明，并通过活动自己的已审映射；不把它强加给普通词块。
- 输入框内键盘留给文本输入与提交，处理 `isComposing`，composition 期间的 Enter 不提交。切课后焦点回到可操作区域，不能困在 select 中。

### 答案与证据

- 每课目标结构答案、已审等价表达、待核对表达分开。基础定向排序可要求指定结构；开放文字未收录时显示“待核对/未匹配本题目标”，不宣称英语错误。
- 归一化限 NFKC、大小写策略、空白、作者允许的末尾标点与撇号形式。否定、词序和承载意义的内部标点不可普遍删除；缩写仅按已审展开/变体接受。
- `Attempt` 以 lesson/version/step/run/attempt 标识，记录 response、时间、类型、反馈前后、hint/example/reference 暴露、结果和是否撤回；同一提交事件去重。
- “首次”指第一次非空且没有帮助的作答。先错后对、查看示例、引导步骤、只识别术语、独立文本与延迟结果分别显示，不能由统一 solved 布尔值推出掌握。
- teach 的继续只表示完成示范，不记概念理解正确。词形引导和讲解后复用不冒充独立测试。

## Risks and rollback

1. **范围膨胀与假覆盖**：以固定子目标清单约束，不追求英语穷尽；一个新交互先落一条真实课程再扩展。遇到计划没有的构式先登记拓展，不自动扩大本次范围。
2. **旧草稿未跟踪**：不能用 git checkout/reset 回滚；执行前对拟改文件保留可恢复副本与路径清单，放专属临时目录或本次 output，保存当前未提交版本。只还原自己的补丁，不能覆盖执行期间用户新改动。
3. **语言与语法分析失准**：采用统一口径，复杂句记录分层与关系。自动检查只能发现结构/覆盖问题，内容自检记录与人工教学审阅状态分开。明显有争议的例句改用无歧义等价材料；实质教学原则冲突才 needs-planning。
4. **回归及模块复杂度**：采用渐进适配，不一次换掉九课；旧数据保留，新增目录可以停用某失败课而不使入口失效。不要把兼容代码延伸到正式学习系统。
5. **学习数据**：只用新 key；损坏时不删除原字串，不做跨账户恢复/迁移。回滚只停用新功能或恢复自己的代码，不清空学习数据。
6. **实际浏览器权限或依赖阻断**：报告具体错误与受影响项；已通过数据测试不抵扣浏览器验收。不能通过切换工具或目标规避限制。
7. **模型/预算导致中断**：本文保持 in-progress，Execution notes 留准确课/批次/测试游标，后续从同一计划继续。不得以时间或 token 不足为理由把未完成条件勾为完成。
