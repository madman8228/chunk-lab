# 自然拼读交互样板

日期：2026-10-24。状态：交互预览已实现，教学音频不齐，未发布为正式课程。

## 范围

用户同意先制作一节完整交互样板，再决定后续课程生产。新增独立 `phonics-lab-preview.html`，不修改已发布课程、release或账户进度；旧课保留。沿用站点暖纸与棕色文字视觉体系，学生提示与教师审核备注分开。

环节为听声音、认对应、看拼合、自己拼、拆声音、试新词。候选对应为 m/s/a（短元音/æ/）/t。示范词mat，迁移词sat；后者不在教学环节展示。四个对应都需在正式解码前提供合格的声音示范，当前不声称已教会。

## 已实现

- 每环节短提示、可导航、原生按钮支持键盘。
- 点字母显示口型文字提示；视觉分步高亮，不假称音频逐音对齐。
- 有序字母格、可撤回/重排、正确与错误反馈。
- 拆分操作以已听完整词mat为材料，不将文字排列判定为发音或音素拆分能力。
- 新词先尝试、可选择不会，自报尝试不记发音正确率。
- 教师说明折叠；学生不需读JSON或掌握判定字段。
- mat整词复用已审原音频，构建时核对原SHA256，不裁切或冒充单音。
- 不使用localStorage、账号API、录音上传或自动发布。刷新后仅重置本页预览。
