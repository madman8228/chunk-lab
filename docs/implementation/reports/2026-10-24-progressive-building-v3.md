## 数据结构

`src/progressive-building/lessons-v3.mjs` 是三课预览入口，复用 `lesson-v3.mjs` 的首课内容。各课显式定义每步中文、独立单词出现项、前置步骤，以及按本步词位置标注的句法范围；角色不再从词典条目的固定标签读取。

三课分别验证：I want 与 to learn English 的局部合成；The book 与 on the desk 的主语内部修饰；Can you help me 与 carry this box 的疑问句动作补充。校验覆盖出现项身份、步骤依赖、标注范围、同层标注冲突和末步目标句。第二课两个 the 使用独立 ID。未制作音频或掌握度测评。

## 页面交互

顶部下拉框切换三课，显示主题而非最终目标句；会话内保留每课进度，刷新后重置预览。每个完成步骤成为一个列表项，保留中文、英文与成分标记。当前步骤只提供本步中文和需要的词。已选单词对应的完整成分范围出现后显示横线及标签，例如 to learn English 整体为宾语；on the desk 为后置定语，The book on the desk 整体另标主语；carry this box 为宾语补足语。部分词组未选全时不提前显示整个范围。长句在内容区横向滚动，避免跨行破坏标注对齐。鼠标、首字母、退格撤回、Enter 继续与重练可用。首字母相同仍按目标词序连续选择；用户曾要求的候选循环切换交互尚未实现。
