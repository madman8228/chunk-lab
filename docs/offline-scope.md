# 当前离线能力与边界

核查日期：2026-10-21。此说明描述当前实现，不是整课离线功能已交付的承诺。

## 已支持

| 内容 | 离线范围 | 前提和限制 |
| --- | --- | --- |
| 首页与基础导航 | 使用已完整安装的页面程序 | 首次访问、下载新版本仍需联网；缓存被浏览器回收后不能保证可用 |
| 我的内容目录 | 本账号、本服务器上一次成功读取的目录与本地已确认数据 | 先显示缓存，再联网更新；缓存目录可能过期，不授予学习权限，也不改写学习记录 |
| 默认课程封面 | 随必备页面程序缓存 | 完整安装后可离线使用 |
| 已浏览的公共课程封面 | 独立缓存，跨页面程序版本保留 | 未访问图片仍需联网；升级只转存公共封面，不转存旧程序或账号接口响应 |
| 学习记录界面程序 | 首次打开时按需加载，以后可命中当前版本缓存 | 版本更新后可能需要重新加载；界面可用不代表统计数据齐全或最新 |
| 已确认记录与待保存操作 | 沿用账号隔离的本地记录及持久队列 | 待同步不等于服务器保存成功；恢复联网后按原有确认协议处理 |

## 登录和个人数据边界

- 正式服务要求先登录，游客页面只提供介绍和登录入口；个人课程、学习记录和正式练习不以匿名账号启动。
- 退出后不显示本机留存的个人记录。已登录设备断网时，可以读取本账号此前确认过的本地缓存；断网无法获知服务端是否刚撤销该账号，因此联网后仍须通过服务器确认。
- 每次个人数据下行和学习保存回执都必须带服务端确认的账号标识。账号不匹配、旧服务器缺少此确认或学习序号回退时，客户端暂停同步并保留缓存和待保存操作。
- 旧服务端需要先升级再部署新客户端。新客户端遇到旧协议会提示服务端更新，不会把匿名数据写入个人缓存。

## 不能承诺离线可用

| 内容 | 当前实际边界 |
| --- | --- |
| 新开启正式平台课程、进入新课节 | 需要在线创建学习会话和取得授权；缓存不能绕过会员、试用或账号校验 |
| 正在学习的正式平台课程 | 仅可能短暂使用已缓存批次和仍有效的授权，不承诺完整离线完成；内容授权最长约 30 秒，过期需要联网续取 |
| 教材词汇目录、单词详情、正式练习状态 | 仍读取 `/api/wordbooks/*`、`/api/vocabulary-items/*`；页面和图片缓存不代替这些接口 |
| 教材词汇插图 | 仍按当前词条加载，依赖共享 HTTP 缓存；不保证刷新、跨版本或浏览器回收后离线可用，不预下载整库 |
| 课程句子音频 | 按实际配置和播放请求加载；当前播放器有短期内存复用及 HTTP 缓存，不保证整课离线播放，未配置音频不可用 |
| 最新统计、排行榜、目录变更、登录及短信验证 | 需要服务器；不能把旧缓存当作最新服务端确认 |

## 缓存与保存原则

- 页面程序使用同一完整版本，不能为离线兼容混用旧程序与新页面。
- 公共封面、账号课程图片、账号目录及学习记录分开管理。账号或服务器切换后不借用旧身份的数据。
- 断网或读取失败不能清空课程、覆盖已确认记录、丢弃待保存操作，不能假报保存成功。
- 身份无法确认或序号回退时暂停自动重试；这代表需要核查账号/数据版本，不等同于普通网络短暂中断。
- 本地缓存不是备份，也不是下载完成证明；首次未下载、存储满、浏览器清理或回收都可能使资源不可用。
- 没有新增“下载整课”或长期离线授权功能；也没有为了本次修改降低授权要求。

## 后续若实施“离线学习”

先限定为用户明确选择的一课，而不是默认整本教材或整库：

1. 服务端签发绑定账号、课节、内容版本及有效期的离线许可，明确会员与试用边界。
2. 客户端按课节下载正文和需要的图片、音频，逐项校验并标明下载是否完整；缺少资源不能显示“可离线学习”。
3. 正式答题继续使用可重放的持久操作队列，区分“已存本机／待同步／服务器已确认”，处理版本变化与重复提交。
4. 回归覆盖断网重开、授权到期、账号切换、存储不足、内容更新及恢复联网；隔离数据目录和端口测试，不能使用真实课程或学习记录作为破坏性夹具。

这部分需要单独实施，不属于此次首次缓存体积修复。

## 验证入口

- `node scripts/sw-install-budget.test.cjs`：首次缓存总量小于 1.5 MiB，统计程序按需加载。
- `node sw-policy.test.js`：版本完整性、按需资源划分和缓存策略。
- `node scripts/offline-covers.test.cjs`：封面跨版本保留、不迁移旧程序、不移除账号图片缓存。
- `node scripts/workspace-offline-directory.test.cjs`：离线重开、后台更新及账号／服务器隔离。
- `node e2e/sw-cache.test.js`：临时数据目录、独立端口和全新浏览器中的真实离线流程及授权边界。
