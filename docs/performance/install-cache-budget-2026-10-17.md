# 首次安装缓存减量

日期：2026-10-17。

## 实施结果

首次安装原子清单从116项、1,976,508 B降到81项、1,564,804 B，减少35项、411,704 B（约20.8%）。恢复通过原有1.5 MiB（1,572,864 B）预算，没有提高限额。余量仅8,060 B，后续前端增长仍应继续运行预算检查。

这是安装清单的未压缩文件总量，不是整个首页的真实网络传输量。页面本身、浏览器PWA安装流程仍可能按需请求图标；真正首次使用独立练习功能时，相关资源仍须下载。

## 简单边界

- 独立单词目录、练习、单词本页面以及对应landing脚本/样式改为按需缓存。小游戏、独立页面主题和契约模块随各自入口加载。
- 180/192/512尺寸品牌图标不再是SW安装的必需下载项，原文件和manifest声明保留，浏览器需要时正常请求与缓存。
- 首页可见Logo、小图标、直接引用的统计脚本、引擎、账号和保存模块继续保留。首页依赖没有为了凑体积移出原子清单。
- 只调整`sw.js`清单归属；未修改页面加载顺序、学习规则、API、数据库或图片编码。所有移动资源仍在版本哈希中，生成器不会重新补入原子清单。
- 未访问过的独立单词页面不再保证刚安装后立即离线可用；使用过且资源已缓存后，可复用当前版本缓存。原有平台学习授权限制不变。
- 沿用已有版本升级/缓存策略，不新增缓存清理。独立课程图片缓存仍跨SW升级保留；未清理真实浏览器、学习记录或课程资产。

## 验证

- `sw-policy.test.js`：21通过，0失败，包括体积预算、哈希、依赖生成幂等与按需资源不回流。
- `scripts/sw-install-budget.test.cjs`：锁定独立练习/大图标按需、首页既有依赖保留、只安装原子清单、按需缓存复用和安装失败不激活。
- `e2e/sw-cache.test.js`：真实浏览器32通过，0失败。新增检查独立练习资源不随首页预缓存、访问后缓存、断网后字节不变、资源不可达不阻碍安装；原有答题确认、离线脚本、联网恢复、权限/账号/版本隔离仍通过。
- 导航与脚本版本一致性、哈希跨换行格式、依赖路径、SW生成结果检查通过。

浏览器测试使用隔离临时数据库、端口与新浏览器上下文，没有访问运行中服务的数据目录。本轮没有重新运行或修改上轮报告的单词本索引生成检查，也没有重建课程索引。

## 生效

未重启或切换真实服务。静态文件发布后，由浏览器接收新SW版本生效；本轮没有操作用户当前浏览器去清缓存或强制更新。线上压缩流量及2核2G服务器承载能力未在此测试中测量。
