# 学习记录模块按需加载验收（2026-10-18）

## 范围与实现

首页和原生练习不使用 StatsGrowth、StatsInsights、MistakeReview、StatsPage，移除 main.html 的四个启动脚本引用，仅在进入学习记录时加载。复用现有脚本加载器，合并同时发生的加载，等待全部请求结束后才允许失败重试；离开页面后的异步完成不抢回导航。重复进入复用已加载模块。

没有修改预缓存资源清单或账号 API 缓存规则。首次 Service Worker 安装仍预缓存其中原有的原子资源，因此本次主要减少启动关键路径工作，不能声称所有用户累计少下载同等字节。

同步重新生成嵌入式学习记录，使先前词汇统计说明的展开状态／焦点修复生效。生成器仅压缩生成 JS 的空白与注释，保留可编辑源文件，避免超出既有 1.5 MiB 原子安装预算。缓存版本为 chunklab-c56031e3。

部署清单补入先前遗漏的 js/personal-center-dialogs.js；没有执行部署或重启。
