# 句子课程离线续学

状态：本地实现及隔离验收通过；2026-10-23 已配置本地 127.0.0.1:8787 签名服务并启动。未部署外部服务器，未代替用户在真实账号答题。

## 已批准范围

- 免费课程：本账号已确认、完整缓存的课节可离线学习。
- 会员课程：离线许可期限为签发后七天与会员到期时间中的较早值。
- 限时试用仍须联网，不签发离线学习许可。
- 许可过期暂停继续学习；保留正文缓存、已完成记录和待同步操作。
- 不增加下载管理、许可管理界面，不自动下载整门课程。

## 已确认的阻塞

- `LearningSessionBootstrap.ready()` 的句子课程调用未允许确认缓存启动。
- `PlatformCourseSource.open()` 总是创建在线学习会话；内存 grant 最长三十秒。
- `ContentGrantService` 使用服务端 HMAC，不能把密钥交给浏览器进行离线验签。
- `CourseContentGateway` 仅保留当前及下一批内存正文，关闭页面即丢失。

## 实施顺序

1. 服务端另签课节级非对称签名离线许可，浏览器仅持公钥；绑定账号、服务、课节、正文版本、用途、签发时间与期限。在线短许可保持独立。
2. 以 IndexedDB 事务保存当前课节完整正文、摘要与许可；只有完整性校验通过才视为可离线。更新失败保留上一完整版本；存储失败明确提示。
3. 仅网络不可达时使用本账号确认缓存及有效离线许可；401/403、账号变更、损坏包、许可过期均不得借缓存放行。保存并校验已观察到的最高时间，检测明显时钟回拨；不宣称纯浏览器能防本机恶意篡改。
4. 复用原持久操作队列及 requestId，验证服务端是否接受有效离线作答；不能因缺在线 session 丢弃已完成答案，也不能放行试用绕过计时。
5. 隔离端口、临时数据库和全新浏览器验证：免费及会员、七天/会员到期截断、试用拒绝、断网刷新/关闭重开、跨批次、账号隔离、重连精确保存一次、存储失败、损坏包和联网拒绝。
