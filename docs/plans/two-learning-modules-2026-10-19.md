# 两大学习模块与场景词汇课程实施方案

状态：材料分层、发布、阅读及听写／选词／词序拼块／跟读工程链路已通过隔离验收；试点内容与真实设备仍待人工验收。不是上线或发布批准。

## 一、假设、目标与非目标

- 产品保留「单词学习」「句子表达」两大学习模块；沿用首页／我的内容／发现／学习记录，不增加第三个一级模块。
- 两个模块平等，不强制先背单词再练句子。句子组装是表达训练的一种方式，不代表全部表达能力。
- 教材词书和场景词书是单词内容的组织方式；词表、对话、短文是材料形式；打字、选块是输入方式。三者不能当作同一组互斥分类。
- 同一句话可服务两个模块，但知识目标和证据不同。看过、听过、有提示完成不自动成为无提示掌握。
- 先用原创「借东西」主题验证内容关系。建议水平 A2，未经人工分级审核，不作已认证等级宣传。不是教材内容，不引用对方软件正文。
- 第一批只有 6 个目标项目、一个单元、两段对话和一篇短文。通过审阅后再扩展为约 3 个短单元；不以凑数量替代内容质量。
- 不改真实课程、编号、学习记录、浏览器数据、备份、权限、收费或复习规则。不自动导入、私有保存或公开发布；不启动另一套成绩保存链路。

## 二、现状与系统性结论

已有目录 topics／levels／教材维度、词书单元、按需读取、配套课程关联、句子填空、中文引导表达、ServerStore 及服务端答案核验。其他四种词汇练习仍声明为未实现。

缺口在「材料与教学目标的明确关联」，不在缺少一个新标签页。目录标签只能用于查找，不能根据标题、拼写相同或 AI 猜测推断知识身份。课级 relatedCourseIds 可用于跳转，但还不足以表达某一对话的具体目标、义项、单元和等级。

推荐在内容制作及校验层先建立关联；前端只展示可用内容和任务。无需前端临时兼容，也不先重构现有生产 schema。

更简单的方案是复制词表／对话／短文页面并硬编码关联；不采用，因为新主题要再次改代码、容易丢失身份和版本关系。反过来，立即建立全局词典／知识图谱也过度；第一阶段只使用独立草稿和现有 WordbookDraft 编译器。

## 三、职责与数据规则

| 对象 | 负责什么 | 不能承担什么 |
| --- | --- | --- |
| 课程与单元 | 学习范围、顺序、稳定编号、版本 | 不代表所有词已经掌握 |
| 教学项目 itemId | 一个明确词义在当前语境下的教学目标 | 不按拼写自动跨课合并 |
| 对话／短文 | 原创双语材料、逐句目标引用 | 不因阅读自动生成答题成绩 |
| 练习类型 | 呈现任务和答案核验规则 | 不冒充内容类别 |
| 输入方式 | 当前任务允许的 typing／chunks | 不改变成绩真实性 |
| 学习事件 | 当前账号、项目／内容版本、任务、提示与结果 | 不从 UI 自称完成直接变成掌握 |

草稿包复用现有 wordbook 草稿，增加只用于审阅的材料旁表。每段材料显式列出所属单元、逐句 targets、双语正文和唯一编号。引用只允许指向本草稿中的目标；重复、遗漏、未知字段、跨单元、伪造可用状态必须拒绝。词性和义项注释留在审阅旁表，不偷偷扩展生产条目格式。

自动校验只能检查结构、编号、引用、目标字面出现和既有练习一致性；不能证明语义自然、翻译正确或 CEFR 合格。人工审阅是独立关口。

## 四、学习流程设计

发现内容保留现有目录结构；后续在「单词」范围提供按教材／按场景的筛选，不新增平行课程仓库。仅展示实际有内容的分类。

主题详情展示目标水平（审核状态）、单元、项目数和可用材料。词表／对话／短文只在存在内容时出现；已知用户续学位置优先，不强制走固定线性流程。

- 词表：先中文词义与语境，再进入现有句子填空／中文引导练习。
- 对话：逐轮阅读、按需中文、显式标注目标词；阅读和练习入口分离。
- 短文：按段阅读，翻译可展开；不强制每单元都有短文，不机械塞入所有目标词。
- 中文引导：完整中文句意保留，当前提示突出；英文只展示已完成部分。Shift 只在允许的输入方式间循环。
- 训练结束：明确「辅助练习完成」。未来独立测评与延迟复习需单独规格，不在本阶段伪造掌握数。

## 八、第一阶段实际结果

- 6 个教学项目通过原 WordbookDraft 文本编译、内容版本和引导配置校验；对话／短文引用只读校验通过。
- 拒绝重复编号、未知字段／目标、跨单元引用、缺双语、缺说话人、错误词义关联的字面目标、遗漏材料覆盖、冒充已审核和未核验图片。语义及分级仍需人工确认。
- 1024／390 两种宽度下，真实 GuidedSentenceView 组件完成六项输入；完整中文保留、错误答案不推进、Shift 循环保留草稿、typing／chunks 结果及完成只触发一次均通过。不是新课程已上线或完整服务端学习闭环验收。
- 发现并修复共用引导组件的句末标点回填问题：展示答案 `pen?` 不能原样填入后面自带 `?` 的槽。现在按题目标准答案回填，显示拆分不变；同样修复句号场景。不改原题、账号保存协议或成绩口径。
- 原有六词引导／隔离保存流程及紧凑词书四宽度回归通过。正式默认编译仍拒绝缺插图，不把文本适配结果当作发布许可。
- 没有重启后端、调用真实账号或发布课程。唯一生产行为修改是上述共用引导答案规范化；新主题仍在独立草稿目录中。

### 防止同类问题复发

以后新增引导内容不仅检查归一化后「句子相同」，还必须通过真实组件完成一遍，核对最终回填值和完整标点。此处由播放器按题目标准答案回填，而不是要求课程作者逐项删除标点，避免新课程重复踩坑。
