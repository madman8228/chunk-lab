# 成人零基础英语课程蓝图与首单元样课

状态：内容规划草案，待审阅；不代表已制作、已发布或达到 CEFR 认证。
日期：2026-10-23

## 定位与边界

对象：中文母语成人，允许不会读英文、不会拼写及听不出词界。儿童与亲子场景另设教学路线。
目标：由真实零基础逐步建立 Pre-A1 到 A1 所需的基础交际能力。采用能力目标组织内容，语法、词汇、音形联系与听说读写共同发展。
规划为 12 单元、60 节教学小课，每单元另有综合任务与延迟复测。课数为制作预算，不是达到 A1 的保证；学习时长需试教后确定。
现有《表达喜欢：饮品》保持原发布标识与内容，映射到单元 4 的试点课，不能静默重编号、改进度或覆盖发布版本。

## 全课程结构

## 贯穿能力与负荷

- 发音：先保证可理解与听辨，再关注重音、弱读和语流；不要求先背完整音标表。字母名与词中发音分开教。
- 词汇：记录“词形＋义项＋搭配＋音频”，同一词不同义项不算自动掌握；新课必须复用旧词。
- 阅读：由图文标签到短句、对话、简单表格和信息；避免把单词拼读训练误当完整阅读。
- 输出：由有提示回答到独立说/写；打字表现不能直接算口语能力，听辨选择不能直接算听说互动。
- 每课原则上聚焦一个交际目标、一个主要新结构、少量新词。具体上限由试教决定，不以统一词数硬塞内容。
- 图片、文字和中文提示逐步撤除；听力题答前不显示原文，答后可回听与看文本。

## 单课活动模板

情境输入 → 理解检查 → 必要微讲解 → 支架练习 → 独立输出 → 新情境迁移 → 后续复习。
按目标选用活动，不要求每课固定九步。固定词块可整体学习，不为排序题拆坏自然表达。
首轮可允许慢速示范，并提供自然清晰语速；慢速音频不能成为唯一验收材料。

## 首单元详细样课

本单元先建立“能参与课程、听不懂会求助”的能力。以下英文与中文均为新编材料，不是来源教材原文。

### U01-L01 听懂最基本的操作

- 前置：无；界面提供中文与图示，不依赖会读英文。
- 目标：听到 Listen、Look、Start 时能选择/执行相应动作。
- 新材料：Listen.（听一听）；Look.（看一看）；Start.（开始）。
- 活动：图标与动作示范；听音选动作；改变图标顺序后再听；最后在新画面中执行指令。
- 过关：无英文文字提示，随机三种指令各出现两次，至少五次首次正确；属于暂定内容阈值。
- 纠错：立即示范对应动作，再用另一个实例重试；原错题不直接变成首次正确。
- 资源：三条真实可播放指令音频、三种清楚动作提示；不需生成装饰插图。

### U01-L02 打招呼与告别

- 前置：L01；核心目标是在见面与离开时选用合适表达。
- 输入：A: Hello! B: Hi! ／ A: Bye! B: Bye!
- 语言：Hello、Hi、Bye；先整体掌握，不扩展所有问候形式。
- 活动：听短对话判断见面/告别；按情境回应；撤掉英文选项后自行说出；换人物验证。
- 验收：四个未练过的见面/告别场景中至少三个恰当回应；另记录实际说出或打字方式。
- 读写：可选抄写 Hello；不能因不会打字阻断听说活动。

### U01-L03 没听清时请求重复（首批重点样课）

- 前置：L01–L02；目标是在没听清时主动说 Again, please.，并在重复后完成任务。
- 微场景：A: Hello, I’m Ben. B: Again, please. A: Ben. B: Hi, Ben.
- 支架：I’m Ben 先作为姓名情境中的输入，不要求本课掌握完整自我介绍规则；Ben 给出音频与人物提示。
- 新目标词块：Again, please.（请再说一遍。）；保留词块整体，暂不增加另一种长句说法。
- 活动 1：看见对话背景，完整听一遍，判断对方是否听清。
- 活动 2：听两个音频反应，选出请求重复的表达；答案位置随机。
- 活动 3：比较 Bye 与 Again, please 在当前情境中的意图，不考术语。
- 活动 4：听示范后跟说；可回听。没有录音评分时只标“完成跟说”，不标发音合格。
- 活动 5：隐藏英文，给出“没听清对方姓名”的情境，独立说出或输入目标表达。
- 活动 6：改成另一人物与姓名，在求助后听重复，并选择匹配的人物标签；测试表达功能而非背原对话。
- 活动 7：后续单元听不清时间或地点时再次调用，不局限于姓名场景。
- 反馈：说明这句话是在请求重复；如用户告别，说明当前交际意图不匹配，不只是显示错误。
- 验收：两个新情境均选对求助意图；独立输出成功一次；次日无英文提示再次使用。只完成即时练习记“完成”，延迟成功才增加掌握证据。
- 自由回答：大小写与末尾标点不作为核心错误；其他自然表达可由内容审核后登记可接受答案，不能把未列举但合理的回答直接当英语错误。

### U01-L04 请说慢一点

- 前置：L03；目标：区分请求“重复”和请求“放慢”。
- 输入：A: Please speak slowly. B: OK.（请说慢一点。／好的。）
- 活动：正常语速与清晰慢速示例；意图匹配；支架跟说；在新短对话中选择并实际使用求助语。
- 验收：两个求助意图各两种新情境，至少三次选择恰当；能独立使用其中一个求助表达。
- 注意：不刻意播放无法理解的高速声音制造挫败；不假设听不懂全是语速原因。

### U01-L05 拼出自己的名字

- 前置：L02–L04；目标：听懂姓名核对并能逐字母拼出自己的名字。
- 输入：A: Your name, please. B: Lin. A: L-I-N? B: Yes.
- 内容：只先练姓名所需字母名，提供完整字母表按需点听；区别“字母名称”和“字母在单词中的发音”。
- 活动：听字母选字母；听姓名拼写；核对正确/错误拼写；独立拼自己的姓名。
- 验收：理解两组新姓名拼写；本人姓名逐字母可辨。没有语音测评时需试听自检或人工抽查，系统不宣称完成口语评分。

## 单元任务与复习

综合任务：进入一个新学习小组，听操作提示、问候、听姓名、没听清时求助、核对本人姓名、告别。使用多个短片段，不能突然要求超出教学范围的自由长对话。
复习安排：完成当日、次日、若干天后再调用，间隔依答题表现调整；具体天数是产品策略，不冒充统一最优科学结论。
报告分开呈现：教学完成、听辨表现、独立文本输出、跟说完成、延迟提取证据；缺失的口语证据不能由打字或排序代替。

## 与现有系统对接

v1.0 的词块、支架输出、听辨、迁移与复习可继续使用；v1.1 的多轮场景仅作后续方向，设计文档不等于已实现能力。

规划 ID 使用 U01-L01 等，与现有 expression-l001-like 分离。旧课映射只在内容清单登记，不改旧发布 ID。
所有新课先形成独立草稿，完成 Schema 校验、文案审核、TTS 试听与资源检查后，再由用户明确批准发布到系统内置目录。

## 首批生产与验收

1. 审阅本蓝图的对象、目标、单元顺序及首单元措辞。
2. 制作 U01-L01 与 U01-L03 两节草稿，验证“零基础听操作”和“求助迁移”两类任务。
3. 按实际 Schema 编码，生成音频并逐条核对文本、声音和资源引用；无可用音频不通过听力验收。
4. 小范围试教，记录看不懂提示、提示依赖、首次作答、重试、独立输出和延迟表现；据此改课。
5. 验证加入、开始、退出续学、版本固定、完成、复习及无音频异常路径后，申请明确发布批准。

待确认：成人是否为唯一首发受众；是否增加口语录音能力；每单元课量与预估学习时间在试教前保持暂定。
