# 独立词卡页宽度旧版显示修复

用户截图的介绍区比导航窄，同时仍显示“从看懂，到用出来”。只读检查确认本地服务已返回“从一个词，到一句话”，但现有浏览器文档保留旧介绍和旧导航。因此不是当前布局计算失败，而是独立页缺少安全应用完整资源版本的更新处理。

新增 `practice-bundle-update`：完成资源版本更新后，仅在可见且没有进行练习、没有打开账号或登录对话框时刷新一次。练习中延迟到返回介绍页；首次安装不刷新；离线保持完整已安装版本。不清理浏览器存储，不迁移账号，不重启服务。

验证：`scripts/practice-page-update.test.cjs` 修复前因缺少更新处理失败，修复后覆盖安全刷新、练习/账号延期、后台延期、首次安装和无循环。隔离实例的 `server/vocabulary-practice.test.js` 检查 1440、1264、1205、390 像素下介绍区及练习区与导航左右边缘差值均小于 1 像素，包含完整拼句流程。此前测试遗漏介绍区，现补全。

旧页面没有此更新代码，安装新资源版本期间仍显示旧页面，安装完成后需普通刷新载入；后续版本自动在安全时机应用。保留 HTML 与脚本来自同一完整资源版本的机制，避免新旧脚本混用。当前用户浏览器已载入新版，实测导航与介绍区宽度均为 652 像素，左右边缘差值均为 0。独立复核结论为 Ship，无阻塞问题。
