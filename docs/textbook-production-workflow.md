# 教材制作与上架

## 两个入口

- **教材生产进度**：核对已审例句、配图、单词音频、句子音频；选择教材执行“打包校验”或“导入待审核”。后者自动完成打包及暂存，不需要先手工打包。管理员入口为 `/textbook-production.html?admin=1`。
- **系统单词课程**：查看已上架教材、处理待审核课程、查询导入历史，以及归档/恢复未发布草稿。这里不管理个人账号课程。

## 流程与保护边界

1. 核定教材版本及源词表，审核原创例句和配图。
2. 按确定文本生成单词、句子音频；抽听与文件完整性核验是两种不同记录。
3. 打包检查词条身份、目标词绑定、文本审核版本、图片和两类音频摘要；交付插画必须为 16:9 WebP，且小于 20,000 字节。
4. 合格课程暂存至系统后台，保留来源审核证据；任一本阻塞不影响其余教材。没有自动发布动作，也不写入个人学习记录。
5. 在后台预览并完成课程审核后，由所有者点击上架。
6. 上架后的错误走“导入修正版”，保留旧版本，经审核后替换当前发布版本。

制作任务持久化在数据目录的 `textbook-production-jobs`。任务刷新后可继续查看；进程中断保留已有结果，再次执行复用同版本已核验的课程包与暂存文件。未完成的打包目录保留供诊断，不覆盖。

例句修订另存于每册 `audio-batches/sentence-revisions`，逐条绑定来源摘要和前一版句子指纹；原稿不改写，修订后仍需新的审核事件和句子音频。更改文本不会继续借用旧音频或旧审核结论。配图匹配允许忽略释义开头的编号（如“（1）颜色”），不忽略词义差异。

已发布导入记录留在历史；已有上架版本的旧首版草稿不再进入待处理队列。归档仅另存状态与操作者记录，不删除或改写原草稿、素材。归档期间禁止上传、审核、发布，恢复后才能继续。已发布记录不提供归档动作。

真实课程变更前使用一致性 SQLite 备份和课程文件备份。测试仅使用临时数据目录与独立端口，不清空真实数据、不迁移账号、不替换已有课程资产。
