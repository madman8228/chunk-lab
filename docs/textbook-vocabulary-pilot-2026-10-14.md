# 教材同步单词课程：第一批人教版试点

## 用户已确认的范围

先做人教版小学、初中、高中各一册，核实可用的官方资料后整理待审稿。不是一次性上线所有年级与所有出版社，不自动导入账号、发布公共目录或修改原课程。

## 内容身份与选择规则

每册以“学段 + 出版社/教材版本 + 系列/起点/学制 + 明确版次 + 年级 + 原册名”区分。不能把小学人教 PEP、精通或一年级起点混为同一版本，也不能把不同出版社的同年级词表合并为一册。

沿用现有分类字段：

| 现有字段 | 用途 |
|---|---|
| schoolStages | 小学、初中、高中 |
| publisherId | 面向用户的出版社/教材版本名称 |
| seriesId | 区分 PEP、精通、起点、学制等教材系列的稳定编号 |
| edition | 核对版权页之后确定的版次，不使用“最新版” |
| grades | 实际适用年级；高中册未确认统一年级时保持空，不猜测 |
| volume | 上册、下册、全一册，或高中教材的必修/选择性必修/选修原册名 |

用户先选学段，再选该学段实际已有的版本、年级、册次；不展示凭空组合的空课程。也允许先选年级，再显示该年级实际存在的版本。筛选是同一组独立维度，不把一个年级硬绑定到一个出版社。新旧版并存时明确标示，不覆盖原册或学习位置。

高中不是统一的“高一上/下、高二上/下”结构；保留教材正式册名，适用年级另作有依据的分类。全一册不得拆成虚构上下册。只有印次改变、正文不变时不因日期不同自动新造课程；核对版次、印次与词表差异后决定。

- 测试验证同年级不同版本、同版本上下册、新旧版共存和筛选不串册；高中保留原册名，不能把上/下册硬套到必修教材。

这些是数据接入准备，不是全站教材选择界面已上线，也不是三册课程内容已经完成。真实服务未重启或切换。

## 获取词表后的验收

1. 核对封面、版权页、系列/起点、版次、册名和目录。
2. 按原单元确认单词、短语、词形、当前词义和书页；专有名词、复习词和扩展词分别处理，不能混充新增核心词。
3. 原教材排序与词条来源保留；学习例句自行编写并标注为原创，不冒充教材原句。
4. 首批每册一个小单元供审阅，明确是局部试点；单元审核后继续追加，整册对照完成才标为全册同步。
5. 插画每种实际文件严格小于 20,000 字节，按当前词汇加载，保留原画；无图文字稿与公开插画发布验证继续区分。
6. 独立内容编号、单元位置和学习记录不覆盖已有课程；用户确认后再导入，公共发布另走内容来源/使用范围和管理员审核。
