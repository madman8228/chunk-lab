# 场景词卡图片体积与导航修正

## 实测文件体积

| 文件 | 原 PNG | 页面使用的 WebP | 减少 |
| --- | ---: | ---: | ---: |
| 六场景合图（1536 × 1024） | 2,735,226 字节 | 291,010 字节（284.2 KiB） | 89.4% |
| 学习页花园背景（1024 × 1536） | 2,399,004 字节 | 172,960 字节（168.9 KiB） | 92.8% |

六幅场景共享一张图，换词不需重复下载；平均每幅约 47.4 KiB，但首次传输为整张 284.2 KiB，不是按单幅加载。两张图片合计约 453.1 KiB，原先为 4.90 MiB。实际加载耗时取决于网络和缓存，未声称固定加载时间。

采用 Sharp 的 WebP 转码：场景质量 78 / effort 6，背景质量 76 / effort 6。原始 PNG 和生成提示记录完整保留。页面 CSS 引用 WebP，Service Worker 六场景缓存入口不再引用原 PNG。首页仍使用它原来的背景，不在本次修改范围内。

## 导航

学习页恢复 Chunk Lab、词卡练习、段位路径、学科；链接均留在当前站点。账号菜单复用 landing/account.js，保留手机号登录、个人信息和绑定功能。导航滚动时保持可见，手机所有功能入口也保留。返回练习介绍只退出本轮界面，不清除课程或学习记录。
