# 单张场景图片 10 KB 预算

## 后续批准：大图单独 20 KB 档

2026-10-11 用户看过画质对比后，批准“大图 20K 以内，小图仍 10K”的分档方案。现仅增加介绍页的 decide 大图：AVIF 19,690 字节 / 512 × 512，WebP 19,988 字节 / 384 × 384。练习中的六词配图和兼容格式仍严格小于 10,000 字节。351 像素及以上视口的介绍图显示宽度超过 320 像素，选择 20K 档；更窄视口用 10K 档。

浏览器按区域大小和格式能力选择，不预先下载两种格式。进入实际练习会再取对应的 10K 小图，因此从大图介绍到首词学习合计约 29K（AVIF），不是仍只下载一张；同一路径后续显示利用浏览器/Service Worker 缓存。原图与两个档位均保留，整词库不预加载。这是画质提升，不能声称网络加载速度比原 10K 更快。

生成脚本默认模式维持旧 10K 工作流；只有显式 `large-intro` 参数生成指定介绍图的两个 20K 文件，不触及 10K 文件。以下表格及“介绍页与首词共用同一文件”描述为调整前记录。

验证包含两个 20K 文件的实际 HTTP 响应大小；320/350/351 像素临界宽度下的新浏览器只请求一个尺寸及一种格式；1440/1264/1205/390 像素的介绍、学习、拼句和返回流程均维持导航对齐。检查整词库不进入 Service Worker 预缓存，账号和练习数据测试使用新临时目录及随机端口。本地页面已应用新样式，服务未重启，线上未部署。

## 原 10 KB 版本记录

以每个实际文件不超过 10,000 字节为上限，不再使用合图平均值。

| 场景 | AVIF 字节 | WebP 字节 |
| --- | ---: | ---: |
| decide | 9,125 | 9,256 |
| borrow | 8,933 | 9,940 |
| advice | 9,667 | 9,876 |
| avoid | 9,278 | 9,578 |
| explain | 9,495 | 9,422 |
| enough | 9,341 | 9,384 |

AVIF 六图合计 55,839 字节，分辨率均为 320 × 320。兼容 WebP 为 192–256 像素。浏览器通过 image-set 只选择一种格式；不支持类型选择的浏览器回退 WebP。当前场景按需下载，原始 PNG 与之前的 WebP 合图保留但学习页不再请求它们，也不再预缓存整张合图。

介绍页与首个词使用同一幅 decide 图片，避免介绍页额外下载另一张。图片首次在线访问后由已有 Service Worker 缓存，未提前整批加载六图。未经访问的图片不保证离线可见；学习文字和操作不依赖图片下载成功。

严格体积限制有画质代价：近看与大屏显示时会少一些细节；不声称与原图无损等效。此预算仅针对词义场景插画，不代表整个页面大小。背景仍为 172,960 字节。

scripts/compress-vocabulary-scenes.cjs 从原 PNG 逐场景裁切，优先保留最高可用分辨率和质量，逐个检查实际字节数。该脚本仅生成指定的 12 个场景分发文件，不修改课程、用户记录或原图。

验证：独立临时数据目录和随机端口下的 server/vocabulary-practice.test.js 检查每个文件预算、当前图片按需加载/单格式选择、桌面手机展示和完整保存流程。
