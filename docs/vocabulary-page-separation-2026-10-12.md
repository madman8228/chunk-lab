# 学单词页面拆分

## 页面职责

- `index.html` 是网站总入口：保留品牌展示、Chunk Lab 与学单词入口、路径介绍及账户菜单；不加载词库数据、学习存储或词卡浏览控制器，不显示六卡、筛选、翻面、换组和统计。
- `vocabulary.html` 是词卡浏览工作台：难度下拉框、当前难度的单词/释义/搭配搜索、类型筛选、六卡浏览、发音、标熟和换组。四张品牌牌背面的链接通过 `?level=J|Q|K|A` 进入对应难度，无效值回退到 J。
- `vocabulary-practice.html` 沿用独立答题流程。全站导航中的“学单词”返回浏览页，不再返回首页的大块操作区。现有六词题仍明确标为“入门场景练习”，不宣称覆盖高阶词库或跟随浏览筛选。

## 解耦及数据保护

原首页内联样式移入 `landing/site.css`，首页与浏览页共享品牌、导航和词卡基础样式；`landing/vocabulary-page.css` 仅处理浏览页布局。首页牌面行为在 `landing/home.js`，词卡行为在 `landing/vocabulary-browser.js`，原 `landing/deck.js`、`landing/phrases.js`、`landing/store.js` 保持不变。未迁移、重命名或清理学习存储，也未修改真实课程及账户记录。继续使用已有账户菜单和登录实现。

首页不再放“选择学习方式”及重复功能按钮；功能选择由顶部导航承担。旧首页 `#deck` 锚点移到 main 元素，仅兼容旧链接，不添加可见占位块。新页面及共享资源登记到运行时依赖和部署清单，Service Worker 按整包更新，避免旧 HTML 混用新脚本。没有部署生产环境，也没有重启本地服务。

## 验证

扩展现有隔离浏览器/API 测试：新临时数据目录、随机端口、新浏览器上下文。覆盖首页不加载词卡界面、手机导航、难度 URL 与回退、搜索与无结果、键盘翻面、标熟刷新保留、桌面/手机无横向溢出，以及进入原答题页的完整练习。缓存版本与部署依赖检查通过。检查首页与浏览页的桌面/手机截图，并修正窄屏搜索标签换行。

## 尚未扩展的功能

本次只拆分页面和整理入口，不新增高阶题库、水平测评、跨端词卡标熟同步或统一的“继续学习”调度。词卡标熟仍沿用原来的本机记录机制；场景练习仍沿用原来的账号自动记录机制。不能把两者混称为已经实现的统一云学习系统。
