# Vocabulary-practice pilot

Scope: the six existing homepage Jack words, with scene-matched examples and declarative sentence cloze in landing/practice-content.js. Other grades retain browsing, without fabricated exercises. Homepage entry opens the dedicated vocabulary-practice.html introduction. Learning never starts inside the landing page. Navigation and learning paper share outer edges. Individual scenes load on demand, never as a full library. Vertical composition uses desktop 16:9 files below 20,000 bytes and mobile 4:3 files below 10,000 bytes, including fallback formats.

Flow: scene above Chinese meaning and an English sentence with inline blanks for the critical targets. For decide: I [decided] [to] have a picnic. No stage tabs, repeated-prefix typing, caption under the image or reveal-step action. Enter moves between blanks and checks the sentence on the last blank; Tab remains native navigation. Errors preserve all answers and focus the first invalid blank. Correct completion shows the full English sentence, translation and audio. Incorrect answers add one end-of-round retry. Exit pauses the DOM, resume preserves every input, skip creates no success and restart resets UI only. See [the generic schema and extension contract](sentence-cloze-architecture-2026-10-11.md).

Credit: all inline-cloze completions, including scheduled reviews, are assisted practice. Supplied context cannot establish independent retrieval or increase mastery. A separate genuinely independent task is needed to earn that credit. Seeing or manually marking a card familiar does not create objective mastery. This pilot does not establish free expression or unseen-scenario transfer.

Scheduling uses server-received events: assisted 10 minutes; initial independent success 1 day; later independent retrievals separated by at least 20 hours extend the interval, capped at 14 days. Two such delayed independent retrievals are required for mastery. This is a conservative pilot heuristic, not a validated optimal-memory algorithm or a promise of permanent retention.

Cloud authority: vocabulary_attempts is a new additive, account-scoped event table. No existing course or learning table is modified. Events use unique IDs for idempotent retry. Local cache and an account-scoped unsent-event outbox are not primary records. Submission retries automatically while the page remains open or after the user resumes a round. An unverified/anonymous visitor uses experience mode with no saved practice results. No new local account partition, manual sync button, course migration or account merge.

Verification: isolated new temporary data directory, random port, no real SMS or course writes. Tests cover account isolation, duplicate IDs, existing scheduling, desktop/mobile practice, six-word completion, generic schema and multiword alternatives, Enter/Tab/IME, answer preservation and automatic replay after network failure.

Future work: author additional grades, validate retention metrics, and integrate these events with unified account exports/reporting. Full database backups preserve the additive table; legacy learning-data JSON export does not yet include these pilot events.
